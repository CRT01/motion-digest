# 动效简报 · 2026-09-01

昨天窗口两份新货：transitions.dev 把产品过渡收成可粘贴的 CSS skill，一份中文 Emil 系审查 skill 把「该不该动」写进同一张表。

### [Transitions.dev](https://github.com/Jakubantalik/transitions.dev)

**类型：** skill

**是什么。** Jakubantalik 的产品过渡配方库，2026-08-31 仍在推。32 个便携 CSS 过渡，选择器统一 `t-*`，变量走语义名（`--badge-*`、`--dropdown-*`、`--modal-*`），不绑 React / Motion / GSAP。skill 源在 `skills/transitions-dev/`：一份 `SKILL.md`、32 个参考文件、以及一次粘贴的 `_root.css`。装：`npx skills add Jakubantalik/transitions.dev`。每个片段都带 `prefers-reduced-motion`。近期补了 Agent 向配方：thinking states、reasoning stream、streaming text。决策规则按「看见的元件 + 动词」匹配，两可时选更轻的（card resize 优于 panel reveal，dropdown 优于 modal）。另有 `transitions review` / `apply` / `refine`：先扫项目里的硬编码 `ms` 和 `@keyframes`，按用途映射到 token，而不是按数字接近硬换。

**何时用。** 要给下拉、模态、页切、骨架、成功勾、Agent 状态行加过渡，又不想拉动画库时。

**可带走的一点。** 时长按用途，不按感觉：`--duration-quick: 150ms`（关模态 / 关下拉 / 文字切换）、`--duration-fast: 250ms`（开模态 / 开下拉 / 页滑）、`--duration-slow: 400ms`（开面板 / 骨架揭示）。默认 easing 是 `cubic-bezier(0.22, 1, 0.36, 1)`（`--ease-smooth-out`）。Agent 状态行：hold `2000ms`，swap `150ms` + `8px` + `2px` blur；隐藏 sizer 锁住最长文案宽度，交换时盒子不要抖。

### [Interface Craft](https://github.com/betterjally-oss/interface-craft)

**类型：** skill

**是什么。** 2026-08-31 新开的中文优先 Agent Skill，自称基于 Emil Kowalski 的设计工程原则，再补层级、完整状态、表单、响应式。审查顺序固定：功能与层级 → 排版间距 → 状态抗压 → 交互动效 → 性能；禁止用动效掩盖结构问题。输出必须是 `Before / After / Why` 三列表，不要拆成普通条目。装：`npx skills@latest add betterjally-oss/interface-craft`。动效段是一份完整决策框架：先问每天出现几次，再问目的、easing、时长，然后才写代码。组件层写了 Button 按压、Popover 原点、Tooltip 连续 hover 跳过延迟、`@starting-style` 进场、clip-path 长按删除。

**何时用。** 审查或补产品 UI（看板、表单、浮层）时，需要同一份中文规则同时管层级和动效。

**可带走的一点。** 键盘触发永远不要动画（Command Palette、快捷键）。UI 永远不要 `ease-in`：同为 300ms，起步慢会比 `ease-out` 更钝。进场禁止 `scale(0)`，从 `scale(0.95)` + opacity 起。时长：按钮按压 100–160ms，Dropdown 150–250ms，UI 通常低于 300ms。自定义曲线用 `cubic-bezier(0.23, 1, 0.32, 1)` 当 ease-out，不要用浏览器默认。
