# 2026-10-22 动效日报

Motion 14.5.0 把「作用域内的 animate/手势/滚动」收成 `scopeMotion` / `useScopeMotion`，顺带用 `matchMedia` 接 reduced motion。同日上线简体中文 Motion Prompt 库（含 UI 包与 Agent Skill）。另补一篇克制派中文长文：先问动效能不能解释变化，再说不清就删。

### [Motion 14.5.0 · scopeMotion / useScopeMotion](https://motion.dev/docs/react-use-scope-motion)

**类型：** 库

**是什么。** 2026-10-20 发布的 Motion minor：`scopeMotion`（`motion`）与 React 版 `useScopeMotion`（`motion/react`）。在一个作用域里启动的 `animate`、`scroll`、`inView`、`hover`、`press`、`drag`、`resize`、`delay`（以及它们回调里再开的动画）会被统一收集；`cancel()` 停掉一切并恢复被改过的 `style`，`stop()` 只停不停样式。可把选择器钉在某个 root 元素内（`"li"` 只匹配列表里的项）；可用 `transition` 给作用域内所有 `animate` 设默认过渡；可用 `matchMedia`（含 `>=800`、`reducedMotion`、`touch`、`hover` 等缩写，或命名条件对象）只在匹配时跑 setup，查询变化时会 cancel 再按需重跑。事件处理里用返回的 `scope.run` / `scope.bind` 才能继续被作用域收集。同日 Motion Studio 2.2.0 加了 Reduced motion mode。文档：https://motion.dev/docs/scope-motion 与 https://motion.dev/docs/react-use-scope-motion ；changelog：https://motion.dev/changelog

**何时用。** 组件卸载要干净拆掉一堆 JS 手势/进场动画；或同一套动效要按桌面/触控/`prefers-reduced-motion` 开关时。

**可带走的一点。** 别再手写一长串 cleanup：把相关 `animate`/`drag`/`inView` 放进 `useScopeMotion(ref, setup)`，卸载即 `cancel`。需要降动时用 `matchMedia: { reduce: "reducedMotion" }`，在 setup 里 `if (!media.reduce)` 再挂装饰性进场——状态反馈仍可用文字/颜色表达。

### [motion-prompt-zh · 中文动效库 + Skill](https://github.com/sadjjk/motion-prompt-zh)

**类型：** skill / 组件参考

**是什么。** 2026-10-21 公开的 Motion Prompt 非官方简体中文版（MIT）：144 个可预览动效，分三大类——界面与网页（`ui` / `lp`）、动态图形（`motion` / `motion2`）、剪辑与摄影（`camera` / `photo`）。编号形如 `#1-001`。在线站 https://sadjjk.github.io/motion-prompt-zh/ ；每个效果带动态示例、中文解释、运动规格与可复制 Prompt。Agent Skill 安装：`npx skills add sadjjk/motion-prompt-zh --skill motion-prompt-zh`。CLI 可 `pick`（浏览器多选回传）、`search`、`get 2-012`、`kit`、`prompt`；实现前读 `references/porting.md`，保留时长/缓动/位移/过冲与 `prefers-reduced-motion`，并保留 MIT 版权行。源自 showheyohtaki/motion-prompt。

**何时用。** 中文对话里要给首页/看板挑可落地的 UI 微交互，或按「文字入场」「弹性」等关键词搜规格再写进现有 React/Vue/原生项目时。

**可带走的一点。** 产品向优先 `--pack ui` / `--pack lp`，用 `get` 读真实规格再移植，不要凭名字瞎写；视频镜头类（`#3-…`）别混进产品微交互验收。

### [动效设计：什么时候动画有用，什么时候该删](https://time2log.com/technology-zh/product-design-learning-14-motion-design/)

**类型：** 设计哲学

**是什么。** 2026-10-16 Time2Log《从会写界面，到会设计产品》第 14 篇（简体中文）。作者用 Where The Sun Sets 复盘：卡片次次飞入、标题次次淡入、按钮次次弹跳，第一次精致、第十次只觉得慢。要求每个动画先回答——是在说明元素去了哪、确认操作已发生、保持空间方向，还是只是「比较有感觉」；说不清就先删。布局跳动、主题闪屏、图片晚到导致整页下移，也算糟糕的「动态」。高频操作要短反馈；`prefers-reduced-motion` 下状态仍须能靠文字/位置/颜色读懂。动效要和真实系统状态同步，不要演完「成功」后台还在转。可中断：600ms 再顺，挡住下一次点击也只是延迟。

**何时用。** 给产品动效做减法评审，或给 agent 定「解释变化才留、装饰先砍」的中文原则时。

**可带走的一点。** 先问「突然跳变用户会不会丢对象/丢因果」；解释连续性的短过渡值得留，制造气氛的叠动画优先删。删完装饰以后，页面往往更像完成品。
