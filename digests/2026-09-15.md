# 动效简报 · 2026-09-15

周末到周一窗口四份：Detent 的墙上面板试样 Bezel、触控优先 H5 动效 token 组件库 Mova UI、硬件感 Motion 控件图鉴 ucc-elements，以及带独立动效章的 Astra 前端 skill。

### [Bezel](https://github.com/TomAs-1226/Bezel)

**类型：** 组件 / 设计哲学 / 试样

**是什么。** 9 月 14 日开源的 UI 屋风试样：把墙面硬件面板的 Material 结构、Apple Liquid Glass，以及昨天简报里的 Detent 可中断弹簧/手势合进一块 720×720 智能家居墙面屏（纯静态页，WebGL2 + DOM，无构建）。规格、token、Claude skill 和 MCP 仍住在 [Detent](https://github.com/TomAs-1226/Detent) 的 `knowledge/bezel*.md`；本仓是可跑的标本。玻璃用双 pass 渲染（场景纹理 → 六级模糊金字塔 → 折射/色散/边缘光合成），DOM 保留命中与无障碍；玻璃形状按家族并集，避免互采假折射。应用窗从图标长出、拖拽可随时打断；Launcher 图标按入场方向级联；待命态十二面平静翻页；Live Activities 可甩进边角 orb。Calm 开关同时关掉折射并按刚度临界阻尼所有弹簧，不是另做一套「残障主题」。

**何时用。** 要看 Detent 数字长什么样、做玻璃/墙面硬件感产品 UI、或审查「玻璃全铺满 / CSS blur 假装折射 / 不可打断的开关窗动画」时。

**可带走的一点。** **玻璃只给控制层，内容层保持实心。** Apple 作用域：dock、分页、岛、运输控件、控制中心模块、活动栈可以浮；瓦片、正文、滑块轨道别糊成玻璃。少了这条，两套语言会糊成廉价玻璃拟态。

### [Mova UI](https://github.com/yzlhdy/mova-ui)

**类型：** 库 / 规范

**是什么。** 9 月 13 日公开的触控优先 React H5 组件库骨架：shadcn 源码组织 + Base UI 唯一 headless + Tailwind v4 + **Motion for React** 统一做状态/进出场/布局与手势。根目录 `DESIGN.md` 与超长 `AGENTS.md` 已写死视觉与工程边界：L1 微动效时长表、`--mova-duration-fast/normal/slow`（120 / 180 / 240ms）+ `cubic-bezier(0.2, 0, 0, 1)`；Popup/BottomSheet 只动 `transform`/`opacity`；禁止滚动劫持、持续装饰动画、视差与 WebGL。Motion 集中在 `src/internal/motion`，对外只暴露 `motion="default" | "none"` 一类语义配置，不把完整 `MotionProps` 泄漏给业务；`MovaProvider` 默认跟 `prefers-reduced-motion`。手势不得成为唯一操作路径。

**何时用。** 在做移动 Web / WebView 产品组件库，要把 Motion 收成设计系统约束（而不是每个组件各写一套弹簧）时。

**可带走的一点。** **H5 动效预算写死：fast 120 / normal 180 / slow 240，标准缓动 `cubic-bezier(0.2, 0, 0, 1)`。** 按压用短时长 opacity/background/scale；浮层只动画 transform+opacity。Reduced Motion 下直接落到终态，别「变慢一点还在动」。

### [ucc-elements（Enochian Elements）](https://github.com/alanism/ucc-elements)

**类型：** 组件 / 配方

**是什么。** 9 月 12 日开源、14 日仍有推送的硬件感控件图鉴：语义 HTML + CSS + JS + `motion`，无托管设计服务。可复制组件含拨盘（含 3/5/7/10 detent）、分段、开关组、旋钮收音机、秒表倒计时、74 键机械键盘、按压按钮等；开启 Code Veil 后一键 COPY。附带厚实的 `coding-reference.md`：从 Drams 触觉控件拆出的 Motion 弹簧配方（`npm i motion`，`import { motion } from "motion/react"`），含 snap / tactile / glide / heavy / gentle 五组弹簧 token、layout FLIP 开关、`layoutId` 分段拇指、按压缩阴影、以及 `layoutId` 防闪五条规则。

**何时用。** 要给开关、分段、旋钮、步进器补「硬件按下」手感，或给 agent 一套可抄的 Motion 弹簧数字时。

**可带走的一点。** 同一手势族共用一根弹簧对象，让轨道和旋钮同到。默认可抄：`snap = { type:"spring", stiffness:700, damping:35, mass:0.8 }`（开关）；`tactile` 用 stiffness 650 / damping 26 做按压缩影。`layoutId` 每帧只能有一个主人——用条件渲染 `{active && …}`，别给同一节点叠 CSS transform 类。

### [astra-frontend-design · motion-and-interaction](https://github.com/Enixes/astra-frontend-design)

**类型：** skill

**是什么。** 9 月 12–13 日上线的 GPT-6 Astra / Codex 前端设计 skill：按任务路由到 art-direction、product-ui、redesign、screenshot-to-code、**motion-and-interaction**、quality-gates 等 reference。动效章很短但方向对：每段动画要有工作（连续性、层级、输入确认、状态解释、或一次有意叙事）；交互反馈可频繁且轻，自主装饰运动要稀。机制从轻到重：CSS → 项目已有 motion 库 → 时间线库（真需要滚动叙事才上）→ Canvas/WebGL（真场景，不是装饰）。要求验初始帧、过渡、终态、中断、重复触发、窄屏与 reduced-motion。

**何时用。** 用 Astra/Codex 做产品或落地页时，需要把「要不要动、用什么动」写进 skill 路由，而不是默认处处 fade-up 时。

**可带走的一点。** **先给动效一份工作，再选最轻机制。** 交易/后台要快反馈与稳几何；作品集才配得上更重编排。`prefers-reduced-motion` 要给有意义的低动效替代，不是把同一动画放慢。
