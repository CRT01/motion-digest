# 2026-10-28 动效日报

本周前两天无新货可报。今天的主菜是 Emil Kowalski 新课 [AI for UI](https://aiforui.dev/)：把「反廉价 AI 界面」写成可教的工作流，并附 28 个 skills 与动效审片工具 Lapse。另两则开源：一套克制微交互 `/motion` skill，以及零依赖的 CSS/TS 小动效组件包。

### [AI for UI · Emil 把品味编进 skills](https://aiforui.dev/)

**类型：** 设计哲学 / 课程

**是什么。** 2026-10-27 Emil Kowalski（Linear 设计工程师，Sonner / Vaul 作者，animations.dev 讲师）公开早鸟课 [AI for Designers and Engineers](https://aiforui.dev/)。定位不是「魔法 prompt」，而是：AI 做出的界面间距飘、动画廉价、模板感重，问题在指挥者——要把自己的品味编码成 rules 与 skills、知道何时放权何时接管，并像专业设计/工程师一样审查产出。早鸟含前 20 课、完整 28 个 UI skills（`/prototype`、`/design-foundations`、`/typography`、`/color`、`/design-system-docs`、`/design-vocabulary` 等）、244 词视觉词汇表，以及自研动效审片工具 **Lapse**（放慢、检视、审动画）。工作流以 Claude Code 为例，原则可迁到任意 coding agent。正式课 2027 年开；早鸟价 $299（原价 $399），报名页写明早鸟至周五 / enrollment closes October 30；团队席位见 https://aiforui.dev/team ，另有给老板的模板信 https://aiforui.dev/boss 。可与免费开源的 `emilkowalski/skills`（animate / review-animations / animation-performance 等）互补：后者是公开规则集，前者是「如何用 AI 还不掉品味」的完整课。

**何时用。** 团队已经用 agent 写 UI，但产出一眼 AI 味；或你想把设计系统品味固化成 agent 可执行的 skills，并有工具专门审动画。

**可带走的一点。** 别再只堆 prompt：先把「什么算好界面」写成 skills/rules，再用 Lapse 一类工具慢放验收动画。早鸟窗口按官网到 10 月 30 日前后，过了就涨价；免费侧继续用 `npx skills add emilkowalski/skills` 拿审查与性能规则。

### [/motion · 有目的的克制微交互 skill](https://github.com/abhimahamkali/motion-skill)

**类型：** skill

**是什么。** 2026-10-27 开源的 Claude Code skill（MIT）：用自然语言 `/motion …` 往站点加冷静、有目的的微交互。捆绑 `motion.css`（时长/缓动 token + `m-*` 类）与 `motion.js`（`reveal` / `count` / `tick` / `auto` / `typing` / `marquee` / `dots` / `scrollSteps`），另有 `references/patterns.md` 约 17 个模式说明。演示：https://abhimahamkali.github.io/motion-skill/demo/ 。安装：`npx skills add abhimahamkali/motion-skill -g -a claude-code`。规则写死：每段动效必须有 job（解释变化 / 展示结构 / 邀请点击 / 表示 live / 奖励操作）；入场 0.6–0.8s ease-out、状态 0.3–0.5s；只动 transform/opacity/clip-path/stroke/色；主按钮 hover 不许位移；自动轮播要有进度、悬停暂停、首次真实点击永久停；一页一个 showpiece；stagger 60–100ms；**绝不滚动 live 价格数字**（用 tick/闪底）；尊重 `prefers-reduced-motion` 与 375px。

**何时用。** 落地页/营销站或产品说明区要「不那么平」，又不想引入 Motion/GSAP；或给 agent 一套带数字的克制微交互菜谱。

**可带走的一点。** 写需求前先给每段动画贴 job 标签；没有 job 就不做。自动播放必须 `e.isTrusted` 点击后停死——别让用户抢不过轮播。

### [drkxbt/motion · 零依赖小动效组件包](https://github.com/drkxbt/motion)

**类型：** 库 / 组件

**是什么。** 2026-10-27 发布的纯 CSS + TypeScript 微交互包（MIT，npm 名 `@drkxbt/motion`，从 GitHub 装以免撞官方 `motion`）：按钮按压/异步保存态/复制/长按确认/磁吸；十组双态图标；switch、滑块 Tab、tooltip、toast、accordion、menu；odometer 计数、spinner、骨架、进度条。用法是给已有 DOM 挂控制器并 `destroy()`，React 里用 effect 清理。主题靠 CSS 变量（`--motion-ease-out`、`--motion-ink` 等）。原则与 Emil 车道对齐：界面动效 &lt;300ms（菜单约 150ms）；入场/按下用强 ease-out；状态用可中断 CSS transition；菜单从靠近触发器的角长出、不从 scale(0) 弹；优先 transform/opacity；`prefers-reduced-motion` 下直接切态。无障碍：真实 button、`aria-busy`、live region、tabs/menu 键盘、hold-to-confirm 对读屏二次按压。

**何时用。** 想在现有 HTML/React 里粘一小撮可验收的反馈动效，又不想拉 Framer Motion 全家桶。

**可带走的一点。** 装包：`npm install github:drkxbt/motion`，再 `import { asyncButton, toast } from "@drkxbt/motion"` + `import "@drkxbt/motion/motion.css"`。验收：连点异步按钮必须可中断/不双提交，菜单从触发角展开而不是屏幕中心缩放。
