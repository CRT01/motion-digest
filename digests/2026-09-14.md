# 动效简报 · 2026-09-14

周末窗口四份：跨端弹簧换算引擎 Detent、给现有界面补过渡的 bera/ui、带核验过的 M3 时长表的 UI 知识库动效章、以及 Compose 里「位移用 spring、特效用 tween」的 Android 出品 skill。

### [Detent](https://github.com/TomAs-1226/Detent)

**类型：** 库 / skill / MCP

**是什么。** 9 月 13 日开源的流体界面动效工具包：零依赖弹簧引擎、约 110 条带出处的 preset、CLI、MCP（10 个工具）和 Claude Code plugin/`detent` skill。核心能力是把同一根弹簧在 SwiftUI / UIKit / Compose / Material 3 / Flutter / Motion / react-spring / CSS `linear()` 等词汇之间互转，并附带动量投影、rubber-band、速度追踪。知识库原则合了 Apple 流体界面（WWDC18→Liquid Glass）、M3 Expressive、以及 Emil / Rauno / Josh Comeau 一线。交互人调 Lab，agent 用同一组数字写代码。

**何时用。** 要选弹簧参数、跨端对齐手感、做 sheet detent / 甩放吸附 / 边缘回弹，或审查「这根弹簧到底弹几次、多久落稳」时。

**可带走的一点。** **`duration` 不是 settling time**——它是无阻尼周期的感知时长，bounce 越大落稳越久。平台默认互相打架：Compose `spring()` 临界阻尼（ratio 1），Android `SpringForce` 默认 ratio 0.5 会弹，SwiftUI `.default` 是 response 0.55 临界阻尼。别背口诀，用 `spring` / `compare_springs` / `export_spring` 读数再导出。

### [bera/ui（bera-motion）](https://github.com/elberacasa/bera-ui)

**类型：** 组件 / skill

**是什么。** 9 月 12 日起公开的 React 产品界面过渡配方库：播放/暂停 SVG morph、可逆列表重排、滑动 Tab、手风琴高度、扩展搜索、滚动数字、图标 morph、文案交接等。每条配方带可调预览、完整 React+CSS 源码、shadcn registry，以及给 agent 的 `bera-motion` skill（`npx skills add elberacasa/bera-ui --skill bera-motion`）。另有 Radix 菜单适配器（`@starting-style` 进场、保留 reduced-motion 与 Radix 退场生命周期）。画廊用「有/无 Bera」并排对比，强调同一状态、同一内容，只差过渡。

**何时用。** 现有 Radix/shadcn/自研控件已经能用，但状态切换仍是硬切，想补上可中断、可反转的过渡而不重做状态机时。

**可带走的一点。** 审查一条过渡按五段：**onset → sequencing → continuity → reversal → settlement**。中途打断必须从当前视觉态继续，禁止排队重放或迟到回调把过期态拽回来；成功反馈跟真实操作结果绑定，演示 replay 不得重复副作用或抢走焦点。

### [Advanced UI Intelligence · motion-interaction](https://github.com/fikriakhdi/advanced-ui-intellegence)

**类型：** skill / 设计哲学

**是什么。** 9 月 13 日发布的反「廉价 AI UI」知识库 + 路由 skill（生成 / 改造 / 批评 / 审计）。动效专章 `knowledge/motion-interaction.md`（标注更新于 9 月 12 日）把一切运动绑在宪法第 12 条：只服务**状态、因果、空间连续、进行中反馈**四类工作，否则就是每次交互都付的延迟税。时长表直接从 `material-web` v0.192 的 `_md-sys-motion.scss` 核验：`duration-short1..4` = 50/100/150/200ms，medium 250–400，long 450–600，extra-long 700–1000；并给出 `easing-standard` = `cubic-bezier(0.2, 0, 0, 1)` 等精确曲线。Apple 数字诚实标成未核验。

**何时用。** 给 agent 做产品 UI 时需要「先论证再动效」，或要一份可引用的 M3 时长/缓动真值，而不是模型背出来的近似数时。

**可带走的一点。** **&lt;300–400ms 别闪 spinner**（会像故障）；骨架要对齐真实布局；高频路径优先乐观 UI，破坏性操作除外。Pressed 反馈要接近 0–80ms；focus ring 几乎即时出现，别给焦点指示器做慢淡入。

### [Android Production Ultimate · Domain 3 Motion](https://github.com/AquaticAzelf/android-production-skill)

**类型：** skill

**是什么。** 9 月 13 日上线的 Android 出品级 agent skill（10 域 / 143 节）。Domain 3（Design / Motion / Adaptive，写在 `references/part-b.md`）把 M3 Expressive 的 `MotionScheme` 和 Compose API 选型表写死成规则：空间运动默认 `spring()`（可中断、带速度），透明度/颜色/模糊用 `tween()` + M3 easing；并给出 stiffness / dampingRatio 用途表、编排规则和 `graphicsLayer` 性能相位约束。动画进度严禁进 ViewModel。

**何时用。** 在 Kotlin + Compose 产品里加共享元素、容器变换、列表 item 动效，或审查「处处 tween(300)」的廉价感时。

**可带走的一点。** **位移/缩放 → spring；淡入淡出/变色 → tween。** 错开入场约 30–40ms/项，总延迟封顶 `min(index * 35, 300)`；bounce 留给庆祝，日常导航用 `DampingRatioNoBouncy`。帧率属性读进 `graphicsLayer { … }`，别每帧 `Modifier.scale()` 触发重组。
