# 动效简报 · 2026-09-10

这窗口三份新东西：Emil 路线动画四件套、风格无关的打磨 skill（含动效十条法）、以及带共享弹簧 token 的 Motion 组件库 skill。

### [Swift Field Guide · Motion 四件套](https://github.com/Fe2-O3/swift-field-guide)

**类型：** skill / 设计哲学

**是什么。** 9 月 9 日上线的 Swift agent skill 合集（22 个），其中 **Motion 家族四件套**是作者按 Emil Kowalski（[emilkowal.ski](https://emilkowal.ski) / [animations.dev](https://animations.dev)）手感标准自研的，不绑 SwiftUI API：`animate` 按「该不该动 → 目的 → 工具 → 属性 → 曲线时长 → 可打断 → 出场」顺序写实现；`find-animation-opportunities` 只扫机会、默认克制（引用 *You Don't Need Animations*）；`improve-animations` 出可执行审计计划；`review-animations` 默认挑刺、批准靠挣。平台无关——Web / React / CSS 同样适用。装法：clone 后把顶层目录拷进 `~/.claude/skills/`。

**何时用。** 要让 agent 按 Emil 栏写/审动效，或先问「这里该不该动」而不是直接堆动画时。

**可带走的一点。** 频率门禁：一天 100+ 次（快捷键、命令面板开关）**永不动画**；UI 入场禁用 `ease-in`（会拖慢用户最盯着的那一瞬）；popover 从触发点 `transform-origin` 缩放，禁止从 `scale(0)` 冒出来（用 `0.95`+透明度）；高频触发用 transition/spring 可改目标，别用会从零重播的 keyframes。

### [ultrapolish](https://github.com/heyimjames/ultrapolish)

**类型：** skill

**是什么。** 9 月 8–9 日推出的两套通用打磨 skill：`ultrapolish-web`（React/TS/CSS）与 `ultrapolish-ios`（SwiftUI）。**不是换一套视觉风格**——先盘点项目自己的字色圆角间距与 motion token，再在系统内把 6/10 推到 11/10。动效写进十条法：同数据同曲线、出场约 0.65× 入场、100× 规则（高频别动）、透明度不走弹簧、spinner 出现在结果将落地处、禁止 layout shift。附时长/缓动表、`visualDuration`+`bounce` 弹簧档位、以及 `gen-springs.mjs` 生成 CSS `linear()`。装法：`npx skills add heyimjames/ultrapolish`。

**何时用。** 审计或边做边打磨产品 UI，想要「克制、跟现有 token 对齐」的动效与细节，而不是再来一套 AI 默认渐变与弹跳时。

**可带走的一点。** 分清 **视觉时长** 与 **弹簧 settle**：0.4s 的视觉时长可能要 ~720ms 才真正停住；用 CSS `linear()` 采样弹簧时必须按 settle 截断，别拿 300ms 表去砍弹簧尾巴。出场用 `exitOf(token)`（时长 ×0.65、bounce 0）。

### [motion-ui-skill](https://github.com/Rkj0123/motion-ui-skill)

**类型：** skill / 组件

**是什么。** 9 月持续更新的离线 Motion（`motion/react`）+ Tailwind 组件 skill：约 130 个可拷贝组件（原语 / AI 对话表面 / Blocks），六种审美预设（minimal、origin、enterprise、glow、ios、brutalist）。真正值得带走的是共享地基 `lib/ease.ts`：命名缓动（`EASE_OUT` `[0.16,1,0.3,1]`、`EASE_EMPHASIZED` 等）与弹簧档（`SPRING_PRESS` 500/30/0.6、`SPRING_PANEL`、`SPRING_SNAPPY`、`SPRING_GENTLE`…），组件统一走这些 token，并接 `useReducedMotion` / hover 能力探测。不是「一百个 loader 合集」那种空壳，但体量大，挑 token 与一两个场景组件即可，别整库灌进产品。

**何时用。** 需要可运行的 React 微交互样板，或想直接复用一套已命名的弹簧/缓动表时。

**可带走的一点。** 按压用 `SPRING_PRESS`（硬、阻尼够、质量轻）；面板入场用 `SPRING_PANEL`；装饰性跟手用 `SPRING_MOUSE`——别让所有交互共用一个「好玩的 bounce」。
