# 动效简报 · 2026-09-09

这窗口四份新东西：中文交互选型词条库、反廉价感 UI 编排引擎里的动效层、Codex 原生雪碧交互动画 skill，以及 Figma Motion 本地轨道插件。

### [UI Interaction Kit](https://github.com/AlphaXe-Hub/ui-interaction-kit)

**类型：** skill / 组件选型

**是什么。** 9 月 8 日上线的 Agent Skill（中文优先，附英文 README）：把「有质感 / 跟手 / 像液体 / 更高级」翻成 **61 个已定义词条**，再动手写代码。覆盖 8 种质感动效（磁吸、液态形变、3D 视差、中心聚焦、液态 Tab、图片展开、手势转场、碰撞回弹）、图表交互、App 模式、展开折叠、导航、弹窗、加载。工作流写死在 `SKILL.md`：**先理解任务 → 默认只选一个主交互 → 再实现**；描述任何交互必须写清触发、开始态、变化过程、结束态、取消态。每个词条有 reference（选型边界、验收清单、英文 Copyable prompt）和可操作 Demo（[GitHub Pages](https://alphaxe-hub.github.io/ui-interaction-kit/)，含「减少动效」开关）。无第三方依赖；参数（弹簧刚度、过冲）被明确标成「设计选择，不是行业标准」。

**何时用。** 产品/图表里要加交互动效、但需求还停在形容词时；或要给 AI 一段可复制的英文实现 prompt、又不想它堆一堆效果时。

**可带走的一点。** 液态 Tab 只动独立指示背景，文字与命中区不动；用前后边缘不同节奏做出「先拉长再收拢」，连续点击必须从**当前可见形态接续**，别等旧动画播完再盖新状态。输入响应优先——柔软和回弹放在视觉规则里，不要人为延迟点击/提交。

### [Universal UI Skills](https://github.com/thakur698/universal-ui-skills)

**类型：** skill / 设计哲学

**是什么。** 9 月 8 日推到 v2.0 的自适应设计引擎：用 7 个编排 skill（creative director → dials → reference-first → composition → visual critic → preflight → design memory）把「Prompt → 代码」换成带批判循环的流水线，专门打「AI-slop」。动效相关两层：`ui-motion` 把运动分成 **MICRO / STANDARD / HERO**，要求每个非平凡动画回答「变了什么、为何要让用户注意到、焦点在哪、会不会拖慢交互、reduced-motion 怎么办」；`ui-anti-slop` 的 Category D 直接否决「每个组件都动画、长入场、无意义弹跳、永久装饰运动、延迟交互的动效」。装法：`npx skills add https://github.com/thakur698/universal-ui-skills`（或 `--skill ui-master` / `ui-motion`）。

**何时用。** 让 agent 出整页/落地页且怕廉价感；或只想给现有界面加一层「该不该动、动多大」的门禁时。

**可带走的一点。** Hero 动效要稀缺：大奖赏、完成态、onboarding 揭示才上；按钮按压属于 MICRO。若结果「可以属于 20 个无关产品」，必须重做，而不是报告成功——装饰服从层级，不是反过来。

### [codex-motion](https://github.com/janice143/codex-motion)

**类型：** skill

**是什么。** 9 月 7 日从 [oil-oil/oil-motion](https://github.com/oil-oil/oil-motion) 分出的 Codex 原生交互动画 Skill：用 Codex **内置 ImageGen**（不是第三方视频 API）做关键姿势 / 姿势表，再本地拆帧、连续性验收、按浏览器预算打 WebP 图集，接到滚动、指针、拖动、触控、姿态、状态或时间驱动。四个事实源：`concept-contract.yaml`、`motion-brief.yaml`、`motion-budget.json`、`final/motion.json`。时间控制分清 `scrub` / `segment-play` / `autonomous`——滚动只是输入源，不自动等于 scrub。量产前强制 Pilot（最多 8 格）。适合产品展开/拆解、有限角度朝向、图标态切换；长镜头/高帧战斗/真实流体明确拒做。

**何时用。** 要在网页里做跟随输入的产品/角色雪碧动画，且环境是 Codex、不想配 ZenMux / 视频 API Key 时。

**可带走的一点。** 先写合同再生成：`driver`、`time_control`、`background_owner`（`page` 要真 Alpha，别绿幕抠图）、画幅跟宿主（Hero `16:9`，局部徽章 `1:1`）。只有位移缩放旋转时走 `deterministic`（程序变换），别浪费 ImageGen 次数；Pilot 失败就改关键帧，别用运行时插值遮素材错误。

### [Orbit Animator](https://github.com/23di/OrbitAnimator)

**类型：** 工具 / Figma Motion

**是什么。** 9 月 8 日开源的 Figma 插件：在 **Figma Motion**（beta）里从选中图层一键生成可编辑轨道——20 个预设（Circle、Arc Carousel、Cover Flow、Tunnel、Pendulum、Vortex、伪 3D Turntable/Sphere 等），可调几何、时序、stagger、缓动、缩放/透明度/旋转/深度，预览后再写入原生 keyframe。完全本地、无网络、无埋点；伪 3D 只用插件目前能写的属性（X/Y、scale、rotation、opacity）+ 图层顺序模拟深度。需本机构建 `dist` 后从 manifest 导入开发插件。

**何时用。** 设计稿阶段就要可编辑的环绕/旋转木马/堆叠路径动画，又不想手抠每一帧时。

**可带走的一点。** 先选顶层 frame 内图层再跑插件；伪 3D 不是真透视——深度靠投影路径、缩放、透明和叠层顺序。API 仍在变，刷新已有 Orbit 动画用插件自带的 refresh，别手改生成轨后期望下次还能无损合并。
