# 动效简报 · 2026-10-14

今天四件产品/UI 车道里的新东西。头条是 Motion **14.2.0**：独立变换（`x` / `y` / `scaleX` 等）终于能走 WAAPI 合成器加速，同日的 **14.1.1** 修了硬件加速弹簧的速度交接。其次是 `enkinvsh/taste`：反廉价 UI + Apple/Emil 物理动效 + 盲测 5 秒验收闸。第三是 `aditya-deokar/gsap-motion-engineer`：12 个 GSAP skill 包 + 反 AI 动效 slop 宣言。第四是 `seukwoo/nudg`：给 AI 可改、可校验的纯文本微交互格式（状态机 + 弹簧）。Emil 本窗口无新帖；优设/ISUX/Ant 无新产品动效 keeper；一批「影视分镜 / 口播剪辑 / goo 装饰组件」按车道剔除。

### [Motion 14.2.0 / 14.1.1（独立变换硬件加速 + 弹簧速度交接）](https://motion.dev/changelog?lib=motion#14-2-0)

**类型：** 库

**是什么。** 2026-10-13 连发两版。以前 `animate(el, { x: 100, scale: 2 })` 这类独立变换每帧都在主线程用 JS 写值再拼 `transform`，只有字面量 `transform` / `opacity` 能走 WAAPI 合成器；主线程一忙（React 渲染、数据计算）就会掉帧。14.2 把同一元素上所有独立变换合成**一条** `transform` WAAPI 动画，跑在合成器上：多轨并行、中断、弹簧保速、`stop` / `pause` / `play`、seek、变速、`repeat: Infinity`、hover 接入进行中的动画都覆盖。缓动尽量压成 2 关键帧 + `linear()` 进度曲线（缺 `linear()` 的老 Safari/Firefox 仍回退主线程）。同日 14.1.1：硬件加速弹簧中断时速度方向/大小校正（以前往更小值跳时会先反方向、小量程如 opacity 几乎丢速度）；`cubicBezier` 更准且约 2× 快；`Reorder` 点击与 `useTransform` Strict Mode 不同步也修了。Motion UI 4.1 同日给 `Gallery` 加了从中心外扩的 `stagger` 与 `from: "last"` 关合，属 Motion+ 组件细节，这里不展开。

**何时用。** 已在用 `x`/`y`/`scale`/`rotate` 独立 API、又遇到主线程争用掉帧；或手势弹簧中断后「弹错方向」。升级：`npm i motion@14.2.0`。

**可带走的一点。** **独立变换现在也可以硬件加速，不必为了性能改回整串 `transform`。** 仍缺 `linear()` 的浏览器会回退主线程；弹簧打断时 14.1.1 起速度交接与主线程一致。

### [taste（反廉价 + 物理动效 + 盲测 5 秒闸）](https://github.com/enkinvsh/taste)

**类型：** skill

**是什么。** 2026-10-13 上线的单体 skill（MIT）。把 AI 前端翻车拆成三件事并对症：① 默认审美（紫光、`Inter`+`slate-900`、三张一样的 SaaS 卡、满屏 ALL-CAPS eyebrow、UI 文案里的破折号）② 死/钝物理（没有 `:active`、`transition: all`、下拉用 `ease-in`、不可打断 keyframes、空闲还在跑 `rAF`）③ 自评偏差（写代码的 agent 看自己截图时上下文已经知道「该是什么意思」）。流水线是：先读现有 token/组件 → 锁表面模式（Persuade / Operate / Read / Experience）和三档旋钮 `DESIGN_VARIANCE` / `MOTION_INTENSITY` / `VISUAL_DENSITY` → 按零容忍反廉价清单构建 → 三道验收闸。动效章蒸馏 Apple《Designing Fluid Interfaces》与 Emil：频率门禁（100+/天键盘操作 0ms；十次级控件 120–200ms 自定义 ease-out；偶发抽屉/模态 200–350ms 或临界阻尼弹簧 `damping: 1.0`）；`:active` 立刻 `scale(0.97)`；禁止 `ease-in` 与 `scale(0)`；弹层 `transform-origin` 锚在触发点；默认弹簧不超调，只有拖拽带真实速度才用 `damping: ~0.8`；只动 `transform`/`opacity`/`clip-path`；空闲 3 秒后 `rAF` 必须为 0。Gate 3 把 1440/390 全屏截图交给**零产品上下文**的多模态模型做 5 秒盲测（中英提示词都给了），主 CTA 置信度 < 85% 或误读状态就回炉，最多两轮。

**何时用。** agent 出落地页/后台壳总带 AI 味，或动效「能动但手感不对」；装法：`npx skills add enkinvsh/taste`。

**可带走的一点。** **完工前跑盲测 5 秒闸：把桌面/手机截图交给不知情的模型，主 CTA 置信度要 ≥ 85%。** 动效默认：按压立刻响应；`cubic-bezier(0.23, 1, 0.32, 1)` / `(0.16, 1, 0.3, 1)`；从 `scale(0.95)+opacity:0` 进场，绝不从 `scale(0)`。

### [gsap-motion-engineer（12 包 GSAP 反 slop 工程套件）](https://github.com/aditya-deokar/gsap-motion-engineer)

**类型：** skill

**是什么。** 2026-10-13 发布（v1.1.0，MIT）。面向 React/Next/Vue/Svelte/Astro/Vanilla 的 GSAP 动效工程包：旗舰 `understand-and-create-animation` 把自然语言译成多框架代码；另有 `gsap-core`、`gsap-scrolltrigger`、`gsap-production-patterns`、`gsap-debugger`、`gsap-performance`、`gsap-react`、`gsap-frameworks`、`gsap-plugins`、`gsap-timeline`、`gsap-utils`，外加总控 `gsap-motion-engineer`。反 AI slop 六律写得很硬：① 焦点克制——只动一个主视觉锚点，次要元数据别全员 `y:50, opacity:0` ② 有机减速——奢华/编辑向用 `power4.out`/`expo.out`（1.0–1.6s），微交互用 `cubic-bezier(0.16, 1, 0.3, 1)` 或 `power3.out`（0.25–0.4s）③ 遮罩动态排版——行/字外包 `overflow:hidden`，从 `yPercent:110` 升到 0 ④ Lenis 与 GSAP ticker 同步，`scrub: 1–1.2` ⑤ `overwrite:"auto"` + `gsap.quickTo()` 可打断 ⑥ 只动合成器属性（`x`/`y`/`scale`/`rotation`/`autoAlpha`）。生产菜谱覆盖英雄区、磁吸按钮、3D 倾斜卡、开场帘、无限 ticker。附 CLI：`node skills/understand-and-create-animation/scripts/generate.js --request "…" --framework react`。

**何时用。** 滚动叙事、遮罩标题、磁吸/拖拽物理要上 GSAP，又怕 agent 写出「全站同一套 fade-up」。装法：`npx skills add aditya-deokar/gsap-motion-engineer`。

**可带走的一点。** **mousemove 跟踪一律 `gsap.quickTo()`，不要在监听器里反复 `gsap.to()`。** 卡片入场默认 `ease: "power4.out"` + `ScrollTrigger.batch()`，禁止动 `width`/`height`/`top`/`left`。

### [nudg（AI 可改的纯文本微交互格式）](https://github.com/seukwoo/nudg)

**类型：** 库 / 规范

**是什么。** 2026-10-13 起公开的 v0.1 草案（MIT，尚未发 npm）。作者认为 Lottie/Rive 这类二进制工作室 资产无法被 LLM 直接改、无法做有意义的 diff/code review。nudg 用严格 JSON（`.nudg.json`）描述：目标名、属性基值、状态机、以及属性如何动到目标。状态只说「去哪」，`animate` 说「怎么去」；中途改目标时从当前值重定位，弹簧默认保留速度。弹簧默认形态是 `duration` + `bounce`（与 Apple 的 response/dampingFraction 可互换；也接受 stiffness/damping/mass）。还有 `kick`（给速度但不改目标，用来做 pop/shake）、颜色 OKLab 插值、具名 motion 库可 `import`。v0.2 加了拖拽 `follow`、松手 `nearest`、值映射 `map`。工具链面向 agent：`validate`（带「你是不是想写 duration」类修复提示）、`simulate`（无渲染看时间线）、`plot`/`render`（曲线图/胶片）、MCP（`nudg_guide` / `nudg_validate` / `nudg_simulate` 等）。参考运行时是 TypeScript headless core + DOM/React 薄适配器；平台只负责绑名与设属性。示例覆盖 toggle、like、拖拽开关等十四个微交互。范围明确：不做骨骼/插画，不做设计系统替换，不做通用状态管理。

**何时用。** 产品微交互（开关、点赞、按压、无效抖动、Tab 指示条）要让 AI 用自然语言改「弹一点 / 快一点」，又希望校验器挡住胡写；适合放进组件旁的源文件而不是丢进 studio。

**可带走的一点。** **「更弹」改 `bounce`，「更快」改 `duration`——一词对一字段。** Toggle 默认弹簧可抄：`{ "spring": { "duration": 0.35, "bounce": 0.25 } }`；校验出错时读 hint 再改，别盲重写整份文件。
