# 动效简报 · 2026-10-15

今天三件产品/UI 车道里的新东西。头条是 `adnanrahim110/ui-motion-skill`：五道决策闸 + 频率→0ms + 进退场时长表，专门挡「过滤器也要等动画」。其次是中文 skill `Shark-Overlord/ui-motion-guide`：按组件类别→交互意图的按钮动效决策树，带 before/after 源码。第三是 `Skryd1X/kinesis-design-studio`：先定方向再实现，动效合同要用 Playwright 录屏验收而不是截图。CHANGELOG 主分支已写 Motion 14.3.0（`stagger` 的 `grid` / `from: "edges"|"random"`），但 npm `latest` 仍停在 14.2.0、无 release tag，本报不收。Emil / animations.dev / 优设本窗口无新产品动效 keeper；大批 Remotion/口播/reel 视频 skill 按车道剔除。

### [ui-motion（五道闸：先问要不要动）](https://github.com/adnanrahim110/ui-motion-skill)

**类型：** skill

**是什么。** 2026-10-14 上线的 UI 动效 skill（MIT），面向 Claude Code / Cursor / Codex 等。核心不是「怎么写 spring」，而是**先决定要不要动画**：① 场景（营销可解释，产品优先速度）② 频率与输入——整天点的 Tab/过滤器/打字/快捷键**立刻**改状态，绝不等人动画结束再导航或发请求 ③ 目的——解释流程、克制触感确认、渐进揭示、空间连续，四条都不沾就保持静态 ④ 删除测试——拿掉后更快更稳就删 ⑤ 执行——写清触发、时长/缓动/弹簧、中断、reduced-motion、静态回退，再选最轻工具。包内默认（可改）：功能 UI 多在 300ms 内；进场 180–250ms、退场 100–150ms；高频 0ms；对话框进场 200–250ms / 退场 100–150ms。曲线预设：`enter [0.16,1,0.3,1]`、`exit [0.4,0,1,1]`、布局 `[0.65,0,0.35,1]`。弹簧起步例 `{ stiffness: 450, damping: 36, mass: 1 }`（近临界阻尼）。附五个可拷 React 示例：渐进对话框、验证码、磁吸按钮、滚动叙事、阅读进度；七份参考按需加载，不全量塞进上下文。

**何时用。** agent 一碰到「加点动画」就给过滤器做淡入、对话框拖住提交，或需要统一进退场合同。装法：`npx skills add adnanrahim110/ui-motion-skill --skill ui-motion`。

**可带走的一点。** **过滤器、Tab、打字这类高频控件：状态变更 0ms，动画绝不能挡请求。** 写动效前先口述合同，例如：`Trigger: open dialog. Entry: 220ms cubic-bezier(0.16,1,0.3,1) opacity+scale 0.96→1. Exit: 120ms. Reduced: immediate.`

### [ui-motion-guide / component-motion-tree（组件动效决策树）](https://github.com/Shark-Overlord/ui-motion-guide)

**类型：** skill

**是什么。** 2026-10-14 发布的中文 AI skill（`component-motion-tree`）。结构是**组件类别 → 类别内交互决策树 → 对应成品源码**，当前第一类是按钮（后续可扩展）。未指定组件时先只读扫描页面列出机会，用户选中后再改；已指定文件则直接识别类别进树。按钮树按意图分流：危险确认 → L9 原地确认；要等结果 → 复制走 L3、请求走 L2；展开菜单/文字 → L4/L7；数字连续性 → L6；组内共享高光 → L5/L8；持久开关 → L10；否则 L1 按压与轻量替换。每个叶子绑一份 `style-1` HTML 成品与 before 毛坯，README 配 60fps before/after 面板。共享实现规矩写得很细：订阅业务状态、固定槽或测宽再过渡、中文用字素边界、`linear(...)` 是采样弹簧不是匀速、减少动态效果时 JS 数字/形态也要跳终态。L2 原始节奏可抄：按压 `scale(0.97)`、文案 240ms、槽宽 420ms；L3 成功驻留约 1900ms，且强调必须检查剪贴板真实写入结果。

**何时用。** 已有按钮/工具栏要加过渡，又不想 agent 凭感觉选动画；或要中文决策路径 + 可对照的成品源码。装法：把 `skills/component-motion-tree` 放进 `.agents/skills/`，或用 `$skill-installer` 装该路径。

**可带走的一点。** **先问「危险确认 / 异步等待 / 展开 / 数字 / 组高光 / 开关」，再打开对应叶子源码——不要凭按钮长什么样选动画。** 异步按钮删掉 demo 的 1300ms 假成功定时器，绑定真实 promise；旧请求用 operation id 防重入覆盖。

### [kinesis-design-studio（动效合同 + 浏览器实测）](https://github.com/Skryd1X/kinesis-design-studio)

**类型：** skill

**是什么。** 2026-10-14 发布的统一设计 skill（MIT + 上游许可证保留）。把艺术指导、有目的动效、响应式工程和证据型验收捆成一条流水线：先发现项目并给出 Quiet Luxury / High-Tech / Editorial 等方向供人选 → 写紧凑的 `DESIGN.md` + `MOTION.md`（角色、触发、起止、时长/弹簧、错峰、中断、几何不变量、reduced-motion）→ 再实现。动效参考明确：按压/悬停确认约 80–180ms，常见状态 150–350ms，大空间 300–600ms；高频任务界面要克制；同一 `transform`/`opacity` 只许一个系统拥有（别让 CSS hover、GSAP、layout animation 抢同一层）。验收要求**录屏与帧采样**，禁止「截图即动效通过」；测中断半途、反转、连点、动画中旋转、离路由、后台回前台、reduced-motion；量帧间隔与长任务，修完再跑矩阵。附 Playwright 描述符快照、布局/命中/层叠探针和动效采样脚本。

**何时用。** 要从零或重做一块界面的视觉+动效，并希望 agent 用真实浏览器证明「能动、可打断、不挡操作」。装法：`python scripts/install.py --agent both --user`，或 Codex `$skill-installer` 指向 `skills/kinesis-design-studio`。

**可带走的一点。** **动效验收必须看录屏与帧，不接受截图绿灯。** 实现前写清合同：谁在动、为何动、打断怎么办、reduced-motion 等价物是什么；同一属性只交给一个引擎。
