# 动效简报 · 2026-09-29

本窗口三件事：`design-skill-lab` 把旧的 `design-motion` 收进 `design-studio`，交出一份带频率门禁的 motion 规范，并在 0.9.0 补上可量化的交互成本章；另有一本 129 条零依赖实机手册，和一套可 `npx shadcn` 拷贝的微交互组件。Motion 库则修了 layout / AnimatePresence / Reorder 几处实战坑。盯着的 Emil skills、AlphaXe、mblode ui-animation、animations.dev 本窗口没有新的产品级增量；优设猎人条目多为 6 月旧稿。

### [design-studio · Motion 规范](https://github.com/caocong1/design-skill-lab/blob/main/skills/design-studio/references/disciplines/motion.md)

**类型：** skill / 规范

**是什么。** `caocong1/design-skill-lab` 在 9 月 27 日的 0.8.0 把原先分散的十多个 skill（含此前消化过的 `design-motion`）收成三个：`design-studio` / `critique-design` / `implement-design`。动效判断落到 `references/disciplines/motion.md`，数值与弹簧记法在姊妹文件 `motion-tokens.md`。`motion.md` 先问「该不该动」——按出现频率分四档（每天上百次 / 数十次 / 偶尔 / 很少），再写目的（反馈、连续、方位、注意、感知速度、性格），再问可否中断、是否只动 `transform`/`opacity`。平台姿态表覆盖 Web、Android Expressive、iOS 系统弹簧、HarmonyOS、Fluent。安装：`/plugin marketplace add caocong1/design-skill-lab` 后装 `design-skill-lab`；站点 https://caocong1.github.io/design-skill-lab/

**何时用。** 给 agent 写产品 UI 时要一份「先门禁、再 token」的动效合同，或要把旧 `design-motion` 用法迁到新三 skill 结构时。

**可带走的一点。** **频率越高越不该动：键盘捷径与每天上百次的操作直接 none；每天数十次最多 150ms 色/透明度；过冲只给偶尔的对话框、路由和长任务成功。** 可逆交互（悬停、开关、拖拽、快速导航）必须从当前位置重定向，禁止定死的 keyframes；退场比进场短约 20–30%；菜单与 tooltip 出现当帧就可点，透明度和缩放 150ms 内收完。

### [Animation Handbook](https://github.com/matinmonshizadeh/animation-handbook)

**类型：** 库 / 规范

**是什么。** `matinmonshizadeh/animation-handbook`（本窗口仍在密集修无障碍与文档）是 129 条 Web 动效技法的可视化手册：滚动 26、进出场 13、页面转场 12、微交互 29、文字 14、3D/高级 18、氛围背景 17。每条都是可离线打开的 `index.html`（零构建、零框架、零 CDN），旁附 `README.md` 讲机制、关键参数与上线坑。在线：https://matinmonshizadeh.github.io/animation-handbook/。微交互章覆盖按压缩放、抽屉、分段控件、焦点环、Toast、下拉刷新等产品控件，不是「一百个 loader」合集。

**何时用。** 要给某个交互找可运行的参考实现，或给 agent / 同事看「这段动效在浏览器里长什么样、参数怎么调」时。

**可带走的一点。** **按压缩放用非对称时长：按下约 80ms（突然接触），松开约 180ms 带回弹缓动（机械回弹）。** 抽屉打开用 ease-out、关闭用更短的 ease-in；分段控件指示器用 `translateX` + `scaleX`，不要动画 `left`/`width`。

### [design-studio · Interaction 规范](https://github.com/caocong1/design-skill-lab/blob/main/skills/design-studio/references/disciplines/interaction.md)

**类型：** skill / 规范

**是什么。** 同仓 9 月 28 日 **0.9.0**：新增 `disciplines/interaction.md`，把「方便、快捷、舒心」变成可算、可查的交付物。内容含 KLM 任务成本串（M/P/BB/K/H/W 及派单算例 11.3s → 2.5s）、键盘模型、快捷键红线、中文 IME（组字期间回车只上屏）、组件行为表（菜单、toast、行内编辑、拖拽排序等），以及「指针下的东西不乱动」。来源表显式含 Emil Kowalski animation；文件写明动效频率与时长仍归 `motion.md`，加载时序归 `product-ui.md`。surface contract 多了 Task cost 块；新算子 `streamline` 只降成本、不改外观。

**何时用。** 设计或评审 Operate 类界面（工具、后台、高频作业流），要把鼠标路径与键盘路径写成可比较的数字，或排查「回车发出拼音」「Toast 里写操作说明」时。

**可带走的一点。** **先砍思考与寻找（M），再砍点击。** 中文输入框：边打边搜、校验、字数统计都等上屏后再响应；判断用 `isComposing || keyCode === 229`（Safari 在确认组字的回车上 `isComposing` 可能为 false）。响应三档仍在 product-ui：0.1s 内输入本身要有回应，1s 内保住思路，超过 10s 给进度与停止。

### [MicroKit](https://github.com/henriquegpb/microkit)

**类型：** 组件

**是什么。** `henriquegpb/microkit` 是面向产品界面的微交互拷贝库：约 49 个带预览的控件（磁吸填充按钮、滑动内容 Tab、扩展图标 Tab、光标边缘光晕按钮、Scrub 数字域等），主张「细节要紧」，源码可读可改。官方进了 shadcn registry：`npx shadcn@latest add @microkit/cursor-edge-glow-button`，也可用 `npx shadcn@latest search @microkit`。站点四种变体（JS/TS × CSS/Tailwind）；CLI 默认写出 TS + Tailwind 单文件到 `components/microkit/`，不塞运行时依赖包。本窗口仍在改站点交互（星标卡、分析监听），组件本体是可持续抄的产品微交互，不是营销片。

**何时用。** 需要一颗带物理感的按钮、分段/Tab 指示器或光标追随反馈，并希望直接贴进现有 React/Tailwind 项目时。

**可带走的一点。** **磁吸位移用指针相对中心的小系数（约 0.14x / 0.22y）+ 220ms `cubic-bezier(.16,1,.3,1)`，填充高度用更长的 380ms 同曲线；离开时归零。** Tab 指示器用绝对定位滑块叠在 `role="tablist"` 上，选中态与内容切换同时长，避免两套互抢的 transition。

### [Motion 13.4.5](https://github.com/motiondivision/motion)

**类型：** 库

**是什么。** `motiondivision/motion` 在 9 月 28 日发 **13.4.5**（changelog 同日更新）。相对 13.4.3/13.4.4 的 Suspense 重播修复，本版修四件实战问题：父级 layout 动画被打断时相对定位子节点跳动；`AnimatePresence` 在某个 exit 完成瞬间若又有子节点经 transition 加入，不再被丢掉；`Reorder.Group` 的 reorder guard 只在 values 变化时清除；`spring` / `useSpring` 体积再小约 5%。站点 changelog：https://motion.dev/changelog

**何时用。** 已在用 Motion 的列表重排、共享 layout、带进退场的视图栈，遇到「父动画打断后孩子跳一下」或「退场刚结束新孩子失踪」时。

**可带走的一点。** **升级到 13.4.5 再查 layout 子节点跳动与 AnimatePresence 丢子；不要在 exit 完成回调里假设树已经稳定到可以同步插入。** Reorder 若自己碰过内部 guard，确认是 values 真变了再清。
