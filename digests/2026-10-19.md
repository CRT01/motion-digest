# 2026-10-19 动效日报

周末到周一新货：落地页「工作室流程」skill、Motion UI Gallery 组件，以及中文审美/商品滚动展示 skill 包。

### [ildargiv/motion-site](https://github.com/ildargiv/motion-site)

**类型：** skill

**是什么。** Claude Code 用的落地页/营销站动效 skill：把 agent 当成动效工作室，而不是「加一堆 fade-in」。流程是 brief（最多四问）→ 选定一种艺术方向（Midnight Launch / Editorial / Swiss Kinetic 等六种，或自建同配方）→ 先写 5–8 场滚动分镜（每场一个想法、before→after、全页只留一个 ★ 高潮）→ 基于自带 Lenis+GSAP+ScrollTrigger+SplitText 的 `starter.html` 开写 → 用 Playwright 脚本 `frames.py` 在 1440×900 与 390×844 拍帧拼接触片，按 idea / composition / motion / typography / rhythm 五轴打分，修最差三处再拍，直到每场 ≥9 或连续两轮不再涨分。附运动语法：进场 `expo.out` ~1.1s、出场 `power3.in` 约一半时长、词 stagger 0.09s、只动 `transform/opacity/clip-path/filter`。硬性 never 清单：居中字+渐变当唯一创意、bounce/霓虹/粒子/劫持滚动/自定义光标 blob、编造数字与客户 logo。不是 AE 片头包，也不是产品内微交互组件库；主战场是有滚动叙事的站点页。

**何时用。** 要做 Awwwards/Apple 级落地页、作品集或会议站，且不想再交「一切同时淡入」的廉价稿；或给已有 `index.html` 加动效但不改文案。

**可带走的一点。** 全页只允许一个高潮（约在滚动进度 60–75%）；若样张仍像 AI 出品，先把「全部同时出现」改成词 0.09s / 块 0.2s 错开，并砍掉一半效果只留那一个 ★。安装：`/plugin marketplace add ildargiv/motion-site` 后 `/plugin install motion-site@motion-site`；审片环需要 `pip install playwright && playwright install chromium`。

### [Motion UI Gallery](https://motion.dev/magazine/introducing-motion-ui-gallery)

**类型：** 组件 / 库

**是什么。** Matt Perry 于 2026-10-14 发布的 Motion+ React 图库组件（Vue 在路上）。用真实 `img`/`video`/`li` + CSS transform 做 2D/3D 排布与共享元素详览，不做 WebGL/canvas，保留可访问性与文本选择。内置八种 arrangement：`list` / `grid` / `barrel` / `coverflow` / `helix` / `ring` / `sphere` / `stack`，可用 `defineGalleryArrangement` 自写。切换排布时不混合矩阵，而是按位置、三轴旋转、scale、opacity 分别插值，并主动压掉「各奔东西」的混乱位移。详览默认原地长大让邻居让路，或 `selection={galleryDetail}` 飞入 `Gallery.Detail`、其余进 `Gallery.Strip`；支持 `detailSrc` 在 pointerdown 预载高清并解码后淡入。手势含拖拽惯性对齐、滚轮、键盘；`tilt`/`ripple` 等 modifier 可接速度；`offset`/`progress` 可接 motion value 做滚动驱动。默认尊重 `prefers-reduced-motion`；只动 transform/opacity；基础包约 19.6kb，含详览约 25.8kb。属 Motion+ 付费组件。

**何时用。** 产品站要做可拖拽/可展开的图片或视频画廊，且需要 helix↔平面详览这类 3D 共享元素过渡，又不想上 WebGL。

**可带走的一点。** 切换 arrangement 时从「当前每一项真实姿态」续航，不要从上一形状的静止矩阵硬切；设计上避免条目朝相反方向乱飞——集合应同向、同进同出地过渡。文档：`import { Gallery } from "motion-plus/gallery"`。

### [zhaodi-Wen/design-agent-skills](https://github.com/zhaodi-Wen/design-agent-skills)

**类型：** skill

**是什么。** 2026-10-18 上线的中文设计 Agent 技能包，两套可分可合：`design-aesthetic-judgment`（审美教练）把参考图拆成「证据 → 关系 → 理由 → 场景化决策 → 验证」，强调注意力路径与可验证关系（层级/布局/字体/色彩/空间/交互），禁止用「高级、简洁」当完成说明，并标明静态图无法验证真实时长与缓动；`scroll-product-showcase`（滚动与拖拽商品展示）用 Vite + Three.js + GSAP 模板做商品落地页：滚动叙事与独立拖拽角度叠加（复位默认只清手动角、保留滚动进度）、结构展开、小程序风格 H5，含 coffee 与 gallery（香水/耳机/腕表）两套可运行模板，要求构建后在真浏览器验开头/中段/回滚/窄屏/`prefers-reduced-motion`。不是 AE 模板，也不是通用 UI kit；偏商品演示与审美迁移。

**何时用。** 要让 agent 讲清楚「为什么好看」再动手；或要可拖拽旋转 + 滚动展开的商品展示页（尤其中文交付）。

**可带走的一点。** 滚动进度与拖拽角度必须分账存储再叠加——两个处理器不能互相覆盖旋转；复位默认只清除手动角度。安装：`python3 scripts/install.py --target "$HOME/.codex/skills"`（或只装其中一套）；新项目用 `create_project.py` 生成到空目录后 `npm ci && npm run dev`。
