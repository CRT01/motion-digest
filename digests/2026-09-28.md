# 动效简报 · 2026-09-28

周末产品向动效有两条线：一条是「动效语言写进设计系统」——`better-design` 把反馈 / 因果 / 减噪写成可验收规则；另一条是 AlphaXe 词条库继续长到 96，补上图标微交互、即时反馈组件，以及一篇独立的弹簧物理方法论。Compose 侧则有 Material 3 Expressive 的 `MotionScheme` 判断 skill。盯着的 Emil / Motion / mblode / animations.dev 本窗口没有新的产品级增量；优设折叠屏开合文仍是 9 月 16 日旧稿。

### [better-design](https://github.com/Moddingflow/better-design)

**类型：** skill / 规范

**是什么。** `Moddingflow/better-design`（9 月 26 日开源）是给 Codex / Claude Code / Cursor 的 UI/UX skill：先读项目 `DESIGN.md`，再做艺术方向、状态、无障碍与验收。动效不是附录——`references/motion.md` 单独成章，要求每个动作先命名功能（反馈 / 因果 / 方位 / 数值变化 / 生命迹象），再落到时长与缓动 token。附带 AI-slop 目录里的动效条目（`scroll-reveal-all`、`bounce-everything`、`attention-everywhere`、`transition: all 0.3s ease` 等），并规定用录像或减速回放验收，禁止用静态截图冒充动效证据。安装：`npx skills add Moddingflow/better-design --skill better-design`。

**何时用。** 新产品或改版要把「界面不能有死瞬间，也不能空转」写进共享规则，或审计一份满屏 fade-up / 弹跳的界面时。

**可带走的一点。** **频率越高、时长越短：每天点几百次的 Tab / 快捷操作只留微反馈或干脆不动；过冲只给有质量感的物体（按压按钮、被拖的卡片），正文和 Modal 禁止弹。** 角色时长起点：`press` 按下 60–100ms、回弹 150–250ms；`micro` 100–150ms；出场大约比入场短三分之一。

### [ui-interaction-kit · 弹簧物理](https://github.com/AlphaXe-Hub/ui-interaction-kit/blob/main/references/13-spring-physics.md)

**类型：** 规范 / skill

**是什么。** AlphaXe-Hub/ui-interaction-kit 在 9 月 26 日加到 **96 词条**：`references/13-spring-physics.md` 不是又一个效果，而是参数方法论——何时用弹簧替代固定时长 easing、`stiffness / damping / mass` 与阻尼比 ζ 怎么取、以及四个可操作 demo（调参台、可中断运动、阻尼三态、惯性抛掷）。文中明确致谢 ckissi/kinetics 的思路，但**不复制其无许可证代码**，demo 为自研积分器。在线：https://alphaxe-hub.github.io/ui-interaction-kit/

**何时用。** 抽屉、拖拽释放、连点换向、指针追随等「会被人打断」的运动要选型，或需要把弹簧参数从玄学变成可讨论的设计选择时。

**可带走的一点。** **会被反复打断、跟手、要惯性 → 弹簧；一次性、要精确编排 → easing。** 中断时只改 `target`，保留当前 `value` 与 `velocity`；按真实 `dt` 积分并 clamp 长帧；收敛后停 rAF 并把值钉死；同一属性禁止和 CSS `transition` 混用。

### [ui-interaction-kit · 即时反馈](https://github.com/AlphaXe-Hub/ui-interaction-kit/blob/main/references/12-instant-feedback.md)

**类型：** 组件 / 规范

**是什么。** 同库 9 月 25 日章：六种「手指刚落下就要看见回应」的控件——多选筛选标签、可删除标签、输入联想浮层、拨动字号刻度、按压倾斜卡片、长按变录音条。相对「手势与反馈」章讲映射数学，这一章讲反馈从哪长出来、邻居怎么让位、松手回哪、中途怎么取消。每条带必须保留规则、英文 Copyable prompt 与验收清单。

**何时用。** 做筛选 Chip、标签输入、按住说话、跟手字号尺等高频触控控件，且要避免「状态等动画结束才提交」时。

**可带走的一点。** **按下到视觉变化 < 100ms：先立刻改样式，弹簧留给松手。** 状态先提交、动画后跟；宽度/增删用布局动画或 FLIP 让邻居平移，禁止瞬移；连点不累积形变。

### [ui-interaction-kit · 图标微交互](https://github.com/AlphaXe-Hub/ui-interaction-kit/blob/main/references/11-icon-microinteractions.md)

**类型：** 组件 / 规范

**是什么。** 9 月 22 日章（上期窗口漏读）：八种图标状态动效——描边绘制、汉堡↔关闭形变、播放/暂停交叉、点赞回弹、铃铛衰减摆动、旋转加载、填充推进、内部元素跟随指针。开篇澄清两件常被带偏的事：主流图标库只有静态 SVG，「动态图标」是自己叠的动效；图标文件是美术资源，许可证与代码分开看（Iconsax Free 禁止再分发松散图标）。Demo 全部自绘几何，不携带第三方图标素材。

**何时用。** 要给 24px 级图标做状态反馈，或审「把 Iconsax SVG 拷进公开 MIT 仓库」这类许可证风险时。

**可带走的一点。** **图标动效 150–400ms，位移不超过自身尺寸的约 1/3；结束后必须回到规范形态。** 点赞：填充是状态、弹跳是反馈，取消路径明显更弱，连点不累积缩放；铃铛角度衰减后精确归零，徽标脉冲与摆动解耦。

### [android-design](https://github.com/charliesbot/android-design)

**类型：** skill / 规范

**是什么。** `charliesbot/android-design`（9 月 27 日拆出独立仓）是 Material 3 Expressive 的 Compose 设计判断 skill：层次、颜色、字号、形状、组件选型之外，**§7 Motion** 与 `references/theming.md` 把 `MotionScheme` 写清楚——空间规格（位姿/尺寸/圆角）允许过冲，效果规格（色/透明度）不过冲；`expressive()` 与 `standard()` 给出六组阻尼/刚度起点。要求自定义动画读 `MaterialTheme.motionScheme`，禁止随手 `tween()`；减动效用 `snap()` 方案替换整套规格。需要 material3 **1.5.0-alpha** 与 `MaterialExpressiveTheme`。

**何时用。** Android / Wear / 桌面 Compose 要上 Expressive，或审「每个 `animate*AsState` 都手写时长」的代码时。

**可带走的一点。** **弹簧感只给空间变化；色与透明度用 effects 规格——用 spatial 规格跑 alpha 会抖。** 屏幕转场保持简单，弹跳留给组件与一两个英雄时刻；全屏导航用平台默认前进/后退，顶层目的之间用快淡入淡出，不要左右滑（与轮播/列表手势冲突）。
