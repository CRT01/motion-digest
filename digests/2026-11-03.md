# 2026-11-03 动效日报

今日五件：Emil 把 Motion 14.2+ 独立变换硬件加速写进 `animation-performance`；mad-ux-motion 把功能 UI 压到 120–180ms 并配 playground；tactile-design 从真实仪表盘抽出可复制的时长/弹簧表；molveau 合并 Emil/GSAP/Lottie 并附零依赖静态闸；以及中文 Codex 的 ui-motion（可中断验收 + 可选零依赖 runtime）。

### [animation-performance · Motion 14.2+ 独立变换可硬件加速](https://github.com/emilkowalski/skills/blob/main/skills/animation-performance/SKILL.md)

**类型：** skill / 设计哲学

**是什么。** Emil Kowalski 性能诊断 skill 在 2026-11-02 合并了 Matt Perry 的修订（[commit f1090bec](https://github.com/emilkowalski/skills/commit/f1090bec277140d02ed202440185ad9d02ac1490)）：从 `motion` **14.2** 起，HTML 元素上的 `x` / `y` / `scale` / `rotate` 缩写会合成进一条可硬件加速的 `transform` 动画，不必再为了躲主线程改写成 `transform: "translateX(…)"`。旧版与仍走主线程的路径写得很清楚：`layout` / `layoutId`、`onUpdate`、`transformTemplate`、惯性，以及每帧由 motion value 驱动的拖拽/`useTransform`。症状表仍是核心：阴影改 `filter: drop-shadow`、导航时卡顿改 CSS/WAAPI、继承 CSS 变量拖慢长大列表、`blur` 动画控制在 20px 内、`will-change` 只在看到跳变或真掉帧后再加。

**何时用。** 动效在导航/水合时掉帧，或你还在用「永远手写 transform 字符串」的旧习惯审 Motion 代码。

**可带走的一点。** 14.2+ 可以安心写 `animate={{ x: 100 }}`；布局动画和逐帧回调仍然在主线程——别把「用了 x」当成「一定不卡」。

### [mad-ux-motion · 120–180ms 功能动效 + 可调 playground](https://github.com/Mad7droid/mad-ux-motion)

**类型：** skill

**是什么。** 2026-11-01 公开的 Codex / Claude Code skill（[`skills/ux-motion/SKILL.md`](https://github.com/Mad7droid/mad-ux-motion/blob/main/skills/ux-motion/SKILL.md)）。立场很明确：功能 UI 默认落在 **120–180ms**（比 Material short3/4 更紧），项目 token 优先；先问频率与目的，再写时长与缓动。硬规则包括：命名 `transform`/`opacity`、禁止 `transition: all`、进入减速/退出加速且退出可更短、缩放入口从约 `scale(0.96)` 而不是 `0`、reduced-motion 要替换而非删反馈、拖拽 `setPointerCapture` 并在真机测。附六块可调 playground：[mad7droid.github.io/mad-ux-motion](https://mad7droid.github.io/mad-ux-motion/)，可切系统/浅/深色、改时长缓动、预览减少动态效果后复制 prompt 或 CSS。审计输出是「文件:行 | 现状 | 改成 | 原因」表，干净就说干净。

**何时用。** 给 agent 一套可执行的功能动效默认值，或要边调边抄配方，而不是又一份空泛「要丝滑」说明。

**可带走的一点。** 把 120–180ms 当成**偏好**写进 AGENTS，不要当成无障碍标准；产品 token 永远盖过这张表。

### [tactile-design · 生产仪表盘蒸馏的动效合同](https://github.com/kosta4a/tactile-design)

**类型：** skill / 设计哲学

**是什么。** 2026-11-01 左右开源的设计工程 skill（[`skills/tactile-design`](https://github.com/kosta4a/tactile-design/tree/main/skills/tactile-design)）：触感、分层、克制的产品界面，动效章 [`references/motion.md`](https://github.com/kosta4a/tactile-design/blob/main/skills/tactile-design/references/motion.md) 明确标注改编自 Emil Kowalski / animations.dev，数值来自真实仪表盘评审。决策顺序写死：谁触发 → 频率档 → 一个目的 → 最便宜工具 → 属性 → 曲线/时长/弹簧 → 可中断 → 布局稳定 → reduced-motion 一起交付。曲线 token 含 `--ease-out: cubic-bezier(.23, 1, .32, 1)`；时长表把 150ms 定为按压/菜单开合主力、退出普遍短于进入；弹簧一律 `{ bounce, duration }`（如分段选择 pill `0.12 / 0.4s`）。还点名 Tailwind v4 裸 `ease-out` 与自定义 `--ease-out` 的冲突，以及「一行共享滑动 hover 高亮」这类反模式。

**何时用。** 要把产品动效写成可复用规范（不只是单次组件），或需要一份带精确毫秒/bounce 的对照表。

**可带走的一点。** 首屏/系统放置的控件用 `initial={false}` 或预摆位置——**只在用户真正操作之后才动画**，否则会显得产品自己在乱动。

### [molveau/motion · 合并门禁 + 零依赖静态检查](https://github.com/molveau/skills/tree/main/skills/motion)

**类型：** skill

**是什么。** molveau/skills（2026-11-02）里的统一动效 skill：把 Emil 全家桶、官方 GSAP skills、LottieFiles motion-design、12 principles、stageshow 与自家护栏收成一份 playbook，并规定冲突时谁赢（例如 UI overlay 总时长压到 300ms，Emil 菜谱里更长的抽屉/toast 让位）。Always-on：先门禁、命名 transition、reduced-motion 落到终态、循环离屏/隐标签暂停、营销站默认不做 scroll-reveal。附零依赖 [`scripts/check-motion.mjs`](https://github.com/molveau/skills/blob/main/skills/motion/scripts/check-motion.mjs)：扫 `transition-all`、`whileInView`/Lenis 等、Tailwind v4 只写 `transform` 却用 `translate`/`scale` 属性会瞬移的坑，以及同文件有 `@keyframes`/循环 `rAF` 却无 reduced-motion 处理。退出码 0/1/2，支持 `--json`。

**何时用。** 想装一套「合并教义」而不是五个分散 skill；或要在 CI/提交前对 `src` 做廉价静态闸。

**可带走的一点。** 跑 `node …/check-motion.mjs src`：清零 `transition-all` 和未处理的循环动画，比再贴一段「注意性能」提示有用。

### [ui-motion · 中文 Codex 组件动效 + 可中断验收](https://github.com/AIGC-Xavier/ui-motion-skill)

**类型：** skill

**是什么。** 2026-11-02 的中文 Web/H5 Codex skill（[`SKILL.md`](https://github.com/AIGC-Xavier/ui-motion-skill/blob/main/SKILL.md)）。按意图路由到六类配方（按压状态、浮层进出、选择导航、重排手势、表单反馈、数据内容），强调动画只呈现既有语义状态、不另起状态机。仓库自带 `node scripts/serve-demo.mjs` 演示中断/连点/键盘，以及测试与校验脚本。可选 [`runtime/motion.mjs`](https://github.com/AIGC-Xavier/ui-motion-skill/blob/main/runtime/motion.mjs) 四个零依赖 helper（`shiftLabel` / `animateValue` / `setPresence` / `animateLayout`），基于 WAAPI；文档写明会临时覆盖元素自身 `transform`/`opacity`，应用前先用专用 wrapper，且业务完成态不得绑在 `finished` 上。未指定分发许可证，接入前需自行评估。

**何时用。** 中文对话里审或补组件动效，并要验证连点、中途取消与 reduced-motion；项目已有动效库时只取流程，不硬塞 runtime。

**可带走的一点。** 完成态跟应用逻辑走：动画 `cancelled`/`finished` 只影响观感，**不要**用 `transitionend` 决定提交或解锁。
