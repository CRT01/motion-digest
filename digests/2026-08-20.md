# Motion digest · 2026-08-20

Seed from the two Bilibili refs: taste skills + Emil Kowalski. Briefs are from reading the actual README / SKILL / docs.


### [emilkowalski/skills](https://github.com/emilkowalski/skills)

**Type:** skill pack

**What it is.** Emil Kowalski (Sonner, Vaul, ex-Vercel/Linear). Source of BV1z2uH6XEbC. Install: `npx skills@latest add emilkowalski/skills`. Skills: emil-design-eng, animate, review-animations, improve-animations, find-animation-opportunities, animation-vocabulary, apple-design, prototype. Product UI bar: no ease-in on chrome, no scale(0), UI under 300ms, no motion on keyboard/high-frequency actions, only transform/opacity.

**When to use.** Write or review interface motion (enter/exit, drawers, toasts, buttons) at Linear/Vercel craft.

**Takeaway.** Enter/exit: ease-out `cubic-bezier(0.23, 1, 0.32, 1)`. Buttons: `scale(0.97)` on :active ~160ms. `transition: all` and `ease-in` are blocks.

### [LottieFiles/motion-design-skill](https://github.com/lottiefiles/motion-design-skill)

**Type:** skill

**What it is.** Philosophy-first: 8-step checklist, personality archetypes, duration/easing tables, Disney-12 for UI, recipes for entrance/exit, state feedback, ambient loops, choreography. Works with CSS, Motion, GSAP, Lottie, springs. Complements Emil (director thinking vs taste/review).

**When to use.** Deciding whether and how something should move, before picking a library.

**Takeaway.** Choreography first. One orchestrated moment beats five random fades.

### [frontend-design](https://github.com/anthropics/skills/blob/HEAD/skills/frontend-design/SKILL.md)

**Type:** skill (taste)

**What it is.** Anthropic official frontend skill. Forces an aesthetic direction before code. Bans Inter/Roboto/Arial, purple-on-white gradients, template layouts. Motion note: orchestrate one load/reveal; extra animation often is the AI look. This is the "what counts as good" half of BV1oq356YEJS.

**When to use.** New pages, redesigns, anything that reads as generic AI UI.

**Takeaway.** Pick one extreme direction and commit. Motion is a signature, not a sprinkle.

### [web-design-guidelines](https://github.com/vercel-labs/agent-skills)

**Type:** skill (audit)

**What it is.** Vercel how-to-fix skill. Fetches live Web Interface Guidelines and reviews files against 100+ rules: a11y, focus, forms, animation (prefers-reduced-motion, compositor-only transforms), type, performance, dark mode, touch. Output is file:line findings. Pair with frontend-design.

**When to use.** Before shipping, or when asking an agent to review UI / a11y / motion.

**Takeaway.** Animate only transform and opacity. Gate hover with `@media (hover: hover) and (pointer: fine)`.

### GSAP skills

Type: official skill pack

What: eight GSAP modules for agents (core, timeline, ScrollTrigger, plugins, React, performance). GSAP is MIT now.

When: scroll stories and timelines, not button hover.

Takeaway: register ScrollTrigger once; useGSAP with a scope in React.

### Motion AI Kit

Type: plugin / skill

What: official Motion kit for agents. Current docs, CSS linear() springs, MotionScore performance grades. Free tier covers best practices and springs. Library is motion/react.

When: default for React product UI.

Takeaway: do not mix GSAP and Motion on the same tree.

### Specs to copy

Type: spec

Zan duration tokens: 100 / 160 / 220 / 280ms, ease-out in, ease-in out.
Ant Design / TDesign / ISUX: restrain motion, only x/y/scale/rotate/opacity, degrade on low-end.
Apple HIG: purpose, brevity, continuity; springs as duration + bounce.

Takeaway: named duration/easing tokens in the design system before adding another library.

### qiaomu-design

Type: Chinese all-in-one skill

What: Xiangyang Qiaomu design advisor. Diagnose, then a 4-direction style fitting room, then DESIGN.md plus a preflight gate. Fuses frontend-design, Vercel guidelines, and Emil motion.

When: one Chinese workflow that already includes Emil.

Takeaway: polish existing pages; do not regenerate from scratch.
