# 动效简报 · 2026-08-20

来自两条 B 站参考：青青王-AI（审美 + 怎么改）和未来奇点FSLab → Emil Kowalski。以下条目都读过原文；英文来源已译成中文。

### [emilkowalski/skills](https://github.com/emilkowalski/skills)

**类型：** skill 合集

**是什么。** Emil Kowalski（Sonner、Vaul，前 Vercel / Linear）的 agent skill 包，也是 BV1z2uH6XEbC 的来源。安装：npx skills@latest add emilkowalski/skills。包含 emil-design-eng、animate、review-animations、improve-animations、find-animation-opportunities、animation-vocabulary、apple-design、prototype。标准是产品 UI 动效，不是 AE 包装：界面不要用 ease-in、不要从 scale(0) 出现、时长压在 300ms 以内、键盘/高频操作不要动效、只动 transform 和 opacity。

**何时用。** 让 agent 写或审查进出场、抽屉、Toast、按钮这一类界面动效，对标 Linear / Vercel 的手感。

**可带走的一点。** 进出场用强 ease-out：cubic-bezier(0.23, 1, 0.32, 1)。按钮 :active 用 scale(0.97)、约 160ms。transition:all 和 ease-in 一律视为不合格。

### [LottieFiles/motion-design-skill](https://github.com/lottiefiles/motion-design-skill)

**类型：** skill

**是什么。** 偏导演思维的动效 skill：8 步清单、性格原型、时长/缓动表、把迪士尼十二条改写成 UI 版本，再加进出场、状态反馈、循环氛围、多元素编排的配方。和 CSS、Motion、GSAP、Lottie、弹簧都能配合。和 Emil 互补：这个决定怎么想，Emil 负责品味和审查。

**何时用。** 还没选库、先要判断该不该动、怎么动、品牌动效性格是什么。

**可带走的一点。** 先编排，再写属性。一次精心安排的入场，好过五个随便淡入。

### [frontend-design](https://github.com/anthropics/skills/blob/HEAD/skills/frontend-design/SKILL.md)

**类型：** skill（审美）

**是什么。** Anthropic 官方前端 skill。写代码前先定一个极端的美学方向，再排版、色板、动效和空间构图。明确禁止 Inter/Roboto/Arial、紫渐变白底、模板化布局。动效备注：编排一次加载/显现即可；到处加动画往往就是 AI 味。这是 BV1oq356YEJS 里「什么叫好看」的那一半。

**何时用。** 新页面、重做、以及现在看起来像通用 AI 界面的东西。

**可带走的一点。** 方向只选一个并贯彻到底。动效是签名，不是默认撒点。

### [web-design-guidelines](https://github.com/vercel-labs/agent-skills)

**类型：** skill（审查）

**是什么。** Vercel 的「具体怎么改」。每次拉最新 Web Interface Guidelines，按 100+ 条规则审文件：无障碍、焦点、表单、动效（prefers-reduced-motion、只动合成层）、排版、性能、暗色、触摸。输出是 file:line。和 frontend-design 配对：一个定品味，这个当 linter。

**何时用。** 上线前，或让 agent 审查 UI / 无障碍 / 动效。

**可带走的一点。** 只动画 transform 和 opacity。悬停动效必须包在 hover 且 pointer:fine 的媒体查询里。

### [greensock/gsap-skills](https://github.com/greensock/gsap-skills)

**类型：** 官方 skill 合集

**是什么。** GSAP 官方 agent skill，八个模块：核心、时间线、ScrollTrigger、插件、工具、React、性能、其他框架。GSAP 已 MIT，旧 Club 插件也免费。时间线和滚动叙事用它；按钮和弹层用 CSS 或 Motion。

**何时用。** 钉住滚动、FLIP、SVG、多段时间线。

**可带走的一点。** ScrollTrigger 只注册一次。React 里用带 scope 的 useGSAP，不要泄漏动画。

### [Motion AI Kit](https://motion.dev/docs/ai-kit)

**类型：** 插件 / skill（原 Framer Motion）

**是什么。** Motion 官方给编程 agent 的工具包：最新文档、不用运行时的 CSS linear() 弹簧、过渡编辑器、MotionScore（给 Motion/CSS/GSAP 打渲染成本分）。免费档：最佳实践 + CSS 弹簧。付费档解锁评分、编辑器和 430 个示例源码。库是 motion/react。

**何时用。** React 产品 UI 的默认选择。就算不引入 Motion 运行时，也可以只要 CSS 弹簧。

**可带走的一点。** 同一棵组件树不要混用 GSAP 和 Motion。负载高时用完整 transform 字符串，不要用 x/y 简写。

### [qiaomu-design](https://github.com/joeseesun/qiaomu-design)

**类型：** 中文一体 skill

**是什么。** 向阳乔木的偏执型设计顾问。安装：npx skills add joeseesun/qiaomu-design。流程：诊断 → 风格试衣间（4 个真 mockup）→ DESIGN.md + 交付门禁。融合了 frontend-design、Vercel 规范和 Emil 动效工艺。作者建议用 GLM 5.2 或 Claude。

**何时用。** 想用一套中文工作流、里面已经带上 Emil，而不是自己拼五个 skill。

**可带走的一点。** 已有页面走打磨模式（审查/批判/抛光/加动效），不要整页重做。

### 规范：抄时长，不要自己发明曲线

**类型：** 规范

- 有赞 Zan：时长 token 100 / 160 / 220 / 280ms，进场 ease-out，出场 ease-in。
- Ant Design / TDesign / ISUX：自然、高效、克制；只动位移缩放旋转和透明度；低端设备降级。
- Apple HIG Motion：有目的、短、连续；弹簧用 duration + bounce。

**可带走的一点。** 先把时长和缓动做成设计 token，再考虑加第三个动画库。
