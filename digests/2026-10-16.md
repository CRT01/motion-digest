# 动效简报 · 2026-10-16

今天四件。头条是 Motion **14.3.0 已上 npm**：`stagger` 原生支持 `grid` 与 `from: "edges"|"random"`，外加 `scaleZ`——昨天 CHANGELOG 已写但包未发，今天可装。其次是 `keyframery`：给现有 shadcn/ui 加一层 `<Cuts />`，对话框从按下的按钮长出、键盘重复操作保持瞬时。第三是零依赖 `liquid-tab-bar`：用高斯凹陷画「球压在膜上」，拒绝 goo blur 只能外鼓的假液态。第四是 Flutter 侧 `morph_expressive`：空间与效果曲线分家，芯片多选用相连变形而不是人人圆绽。Emil 本窗口无新产品动效文；大批 Remotion/口播/reel 与电影感落地页 MCP 按车道剔除。

### [Motion 14.3.0（stagger 网格 / edges / random）](https://motion.dev/changelog?lib=motion#14-3-0)

**类型：** 库

**是什么。** 2026-10-15 发布并已上 npm `latest` 的 Motion 小版本（昨日主分支 CHANGELOG 已写、包未发，本报补收）。新增：`stagger` 的 `grid: [columns, rows]`——按阅读顺序把元素当成网格，延迟按到起点的二维距离（`Math.hypot`）算；`from` 扩展为 `"edges"`（两端/外缘先动、向内收）与 `"random"`（每个元素一步、同元素数下顺序稳定）。`from` 仍支持 `"first"|"last"|"center"|index`。另加 `scaleZ`。修复：`matrix3d` 等数字名 transform 被误当成数字、`useSpring` 切换目标时跟到新目标、SVG 的 MotionValue children 写成 children 属性。源码在 `packages/motion-dom/src/utils/stagger.ts`；公开 docs 页仍写「尚不支持 grid」，以 CHANGELOG / 源码为准。

**何时用。** 图标网格、工具条、卡片墙要「从中心散开 / 从边缘收进 / 乱序入场」，又不想手写距离函数。升级：`npm i motion@14.3.0`。例：`delay: stagger(0.05, { grid: [4, 3], from: "center" })` 或 `from: "edges"`。

**可带走的一点。** **网格错峰用 `stagger(..., { grid: [cols, rows], from })`，别再自己算行列距离。** `"edges"` 适合外缘先亮、向内收齐；键盘/高频重复操作仍应 0ms，与错峰进场无关。

### [Keyframery（一行 `<Cuts />` 给 shadcn 上动效）](https://github.com/keyframery/keyframery)

**类型：** 库 / 组件

**是什么。** 面向 shadcn/ui 的产品动效层（MIT，约 12KB gzip，无运行时动画依赖：CSS + WAAPI）。根布局挂一次 `<Cuts />`，按 `data-slot` 找到现有 Dialog / Sheet / Drawer / Tabs / Toast 等，**不改 `components/ui`**。对话框默认 rack-focus：从按下的按钮长出再合回；Sheet 滑入时页面后沉；Tabs 做 J-cut（指示条先动、面板跟拍）；Toast 从触发按钮飞出。另有五件帮手：`MatchCut`（卡片→详情）、`ListCut`、`ValueCut`、`LoadCut`、`StateCut`。主题 Quiet / Crisp / Expressive 可调；`pace` 倍率全局或单点。克制点写得很清：键盘改日历/滑块保持瞬时；提交后才 shake，打字中不抖；标签/分隔符/快捷键标注故意不动。`prefers-reduced-motion` 下只剩 120–160ms 淡出或瞬间切换。附 MCP（`https://keyframery.com/mcp`）与 Claude Code 插件。0.2.x 覆盖全部 63 个 shadcn 组件的 cut / response / still 表。

**何时用。** 已有 shadcn 应用要统一动效，又不想给每个 Dialog 手写 Motion。装法：`npx shadcn add @keyframery/cuts`，根布局 `{children}` 后渲染 `<Cuts />`。

**可带走的一点。** **产品动效要绑「谁触发」：对话框从按钮长出；键盘连按保持瞬时。** 标签和永不变化的零件保持静止——动了只是噪音。

### [liquid-tab-bar（高斯凹陷底栏，真压膜）](https://github.com/everyoneneedsasamwise/liquid-tab-bar)

**类型：** 组件

**是什么。** 2026-10-15 上线的零依赖底栏（~4KB，MIT，`npm i liquid-tab-bar`）。球跟指针，条面被压出凹陷——像保龄球压在床垫上。关键实现：每帧重算 SVG `path`，表面高度是以球心为中心的**高斯凹陷**加一道微抬「肩」；作者明确反对 goo blur——模糊只能把形状往外鼓，不能往里压。球用 `requestAnimationFrame` lerp（`LERP=0.26`）追目标，带一点液体滞后。渐进增强：真实 `<a>`，hash 或路径导航，`aria-current`，`:focus-visible`；`prefers-reduced-motion` 时球瞬移、不缓动。可 `LiquidTabBar.mount(el, { onNavigate })` 接管 SPA 路由。

**何时用。** 移动端/PWA 要一条有重量感的底栏，又不愿上滤镜 goo 或重框架。Demo：https://everyoneneedsasamwise.github.io/liquid-tab-bar/

**可带走的一点。** **要「压进去」的液态感，用几何算凹陷，别用 goo blur（blur 只会外鼓）。** 减少动态效果时直接跳终态，不要半拉子缓动。

### [morph_expressive（Flutter：空间/效果分曲线 + 相连芯片）](https://github.com/Bruno0416/morph_expressive)

**类型：** 库 / 规范

**是什么。** 2026-10-15 推进的 Flutter 设计系统（0.2.0 准备发 pub；独立 fork Material 3 Expressive）。`doc/MOTION.md` 把词表收进 `MorphMotion`：**空间**（形/缩放/位移）允许适度过冲；**效果**（透明度/颜色/遮罩）用有界曲线、弹簧近临界阻尼，禁止给 opacity 上过冲。提供 `spatialTween` / `effectsTween` / `staggeredTween`（`TweenSequence`，延迟走同一时间轴，不用另开 Timer）。亮点在 `MorphChipToggle` 多选：空→第一枚与最后一枚取消才用圆形绽放；中间增删是从最近选中芯片**复制/合并并交错拉伸**（默认约 289ms，尾沿延迟约 77ms）。另有全局触觉开关、填充输入框标签斜向浮起、Tab 默认不因焦点乱滚视口。

**何时用。** Flutter 产品要在 M3 Expressive 之上统一空间/效果两套曲线，或做「相连」的多选芯片而不是每颗独立圆绽。

**可带走的一点。** **空间可以过冲，效果（opacity/color）不要过冲。** 多选芯片：只有「空集合的第一枚 / 最后一枚取消」走圆绽，其余用相连变形。
