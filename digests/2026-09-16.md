# 动效简报 · 2026-09-16

昨天到今早窗口三份：从 30 个真实站点测出来的 df-design 动效配方、用浏览器拆入口/滚动手感的 atelier teardown，以及从 live URL 取证 GSAP/Motion 参数的 ui-clone-skills。

### [df-design](https://github.com/jounimn/df-design)

**类型：** skill / 设计哲学

**是什么。** 9 月 15 日上线的网页设计与动效 skill：先强制声明 `mode=motion | design | both`，再按模式读配方。证据来自对 30 个量产站（Stripe、Linear、Vercel、PostHog、Hex、Neon 等）的真实浏览器测量——字号、字距、页高、字体面数、圆角，以及是否尊重 `prefers-reduced-motion`。核心结论不是「多写 keyframes」：读得起贵的页面更多靠 **mask / clip-path / blend-mode** 和一层廉价氛围循环；配方文件 `references/recipes-motion.md` 给的是可跑代码，不是「400ms ease-out」参数表。完工门禁是「必须看过渲染后的页面」，截图还要求页面处于静止终态，避免滚动触发内容被拍成 `opacity: 0`。

**何时用。** 做落地页/产品营销面的动效身份、或 agent 一开口就到处 fade-up 时，需要用实测配方把「什么在动、为什么动」钉死。

**可带走的一点。** **签名曲线只选一条，大约 80% 的过渡都用它。** 可抄：`--ease-signature: cubic-bezier(0.25, 1, 0.5, 1)`（Stripe 高频）、`--ease-weighted: cubic-bezier(0.32, 0.72, 0, 1)`（Linear）、时长档 feedback 0.15s / content 0.3s / showpiece 0.8s。组内总 stagger 压在约 500ms 内；reduced-motion 下保留纹理、关掉运动。

### [atelier · teardown](https://github.com/amir-salmani/atelier)

**类型：** skill / 工具

**是什么。** 9 月 15 日公开的产品设计方法仓，三件套里动效相关的是 **teardown**：用 Playwright 驱动真浏览器，把入口动效、滚动编排、缓动与时长、stagger 节拍、移动端构图、以及 `prefers-reduced-motion` 诚实度读成可引用证据包（入口/滚动/移动 contact sheet + `motion.json`）。README 里已写清盲区：Canvas/WebGL 只有帧没有规则、入口时间轴因 CPU 限流会偏慢（看顺序与比例，别看墙钟）、采样时长与声明时长不要混比。配套 `inspire` 才允许把参考变成方案；单独 teardown 禁止直接抄皮。

**何时用。** 参考是一个 URL 而不是截图、要回答「这个站的入口/滚动到底怎么动」、或给 agent 建立可引用的动效资料库时。

**可带走的一点。** **先看 contact sheet，再读五个数。** 家门节奏：medianDurationMs 约 200–400ms 算自信；stagger gap 60–120ms 像同一手势，超过 200ms 像排队；medianTravelPx 小于 24px 是落定，超过 80px 必须有理由。`reducedMotionMediaBlocks` 为 0 往往说明动效是装饰而不是设计。发布数字只引用 `evidence.json`，别引用会随重跑被覆盖的原始包。

### [ui-clone-skills](https://github.com/voidmatcha/ui-clone-skills)

**类型：** skill / 工具

**是什么。** 9 月中旬持续更新的 Claude Code / Codex 插件：输入 live URL，走捕获 → 解码 → 重建 → 验证，目标是复刻**怎么动**而不只是长什么样。会从 CSS 与 JS bundle 抽出 GSAP/ScrollTrigger、Framer Motion / Motion 弹簧、Webflow IX2、Lenis、Lottie 等参数，写成共享的 `transition-spec.json`，再用布局门禁、AE/SSIM 与 60fps 运动对比验收。构建成功、HTTP 200、或「截图像」都不算完成；滚动终点、显现触发、悬停/点击与过渡状态要对得上。中文 README 已同步说明边界：不是 v0 式设计生成器，也不该用来绕过授权去抄别人产品。

**何时用。** 授权范围内要高保真复刻带滚动显现/弹簧/时间线的页面段落，或审查现有实现是否真覆盖了参考动效时。

**可带走的一点。** **实现和验证共用一份观测契约（`transition-spec.json`），别各自猜缓动。** 事件触发不等于轨迹一致：要在滚动活跃区间内对比中间态。完成前 unset 迭代范围变量，跑完整所选 scope 的验证；桌面验过只能声称 desktop-only verified。
