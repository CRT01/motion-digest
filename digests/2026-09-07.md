# 动效简报 · 2026-09-07

周末窗口里三份新东西：一份把 Motion（motion.dev）蒸馏成「手感判断」的多语言 skill、一份可编辑 Rive 出片与验收 skill，以及一份把 UI 录屏量成可改 GSAP 场景的测量工具。

### [Dynamization](https://github.com/chanLik1208-dev/Dynamization)

**类型：** skill / 设计哲学

**是什么。** 9 月 6 日新开的 Agent Skill（也当可读文档用）：把 Motion（原 Framer Motion）从「API 说明书」翻成「为什么这段动效看起来假」。双支柱——**Motion（时间）**：从哪来、去哪、现在能不能点；**亮度对比（空间）**：谁在上面、谁还活着、此刻该看哪。核心观点：所谓「抬起」不是把元素上移 4px，而是位移 + 更大更软的阴影 + 更亮表面同时发生，大脑才会读成「靠近我」。仓库含 `SKILL.md`、`feel`/`contrast`/`recipes`/`pitfalls`，以及 React / vanilla / Vue 参考；判断章有繁中/日/韩/西语完整译文（API 章故意只留英文）。装法：`git clone` 到 `~/.claude/skills/dynamization`（或项目内 `.claude/skills/`）。还纠正了官方文档里 spring `stiffness` 默认写成 `1` 的错误——源码是 `100`，照文档写会出现几乎不动的弹簧。

**何时用。** 写/审 Motion（React/Vue/vanilla）过渡、弹簧、编舞、elevation；或有人说界面「生硬 / 廉价 / 没层次」却说不出原因时。

**可带走的一点。** 位置与尺寸用 spring，透明度与颜色用 tween——这是 Motion 源码 `getDefaultTransition()` 的默认逻辑，不是品味：`x/y/rotate` → `stiffness: 500, damping: 25`；`scale` → `550/30`（临界阻尼、禁止弹跳放大）；`opacity/color` → 0.3s tween。spring 真正值钱的是**打断时带着当前速度续上**，不是弹性。出场约入口时长的 0.5–0.7×、路程更短。Hover 别超过 0.2s。深色主题阴影几乎看不见，elevation 要靠更亮表面，换主题是换机制不是换色板。

### [rive-animation-skill](https://github.com/jeongjin98/rive-animation-skill)

**类型：** skill

**是什么。** 9 月 6 日发布的可移植 Rive Agent Skill（Codex / Claude Code / Cursor）：覆盖插画拆分与绑定、关键姿势与时序、状态机与数据契约、以及**真实回放验收**。入口 `skills/rive-animation/SKILL.md`，按任务路由到 artwork-rigging / motion-recipes / mcp-operations / interaction-runtime / verification。它只提供说明书，不自带 Rive、MCP 或渲染器；编辑依赖本机 Rive 桌面端 MCP（文档写的是 `http://127.0.0.1:9791/mcp`），视觉质量必须看实际播放，不能拿状态机日志当「好看」。README 诚实写明：AI 生成、主观收益、测试有限，主价值在**改稿循环**（保留已批准部分、针对性修正），不保证一次出片完美。

**何时用。** 从参考图做可编辑 Rive 角色/场景循环、改 walk/idle、接进度条或点击交互，或只想先出生产计划时。

**可带走的一点。** 把**镜头运动、角色在场景中的位移、环境动画**拆开写进 brief——「固定镜头」不等于窗外风景也冻结。完成报告要分开写：结构 / 逻辑 / 视觉 / 导出 / 运行时；没看到真实回放就标明「视觉未验证」，别把设计配方当成已验收资产。

### [Keepframe](https://github.com/westernbear/Keepframe)

**类型：** 库 / 工具

**是什么。** 9 月 7 日公开的 Python 工具（alpha）：把**平面 2D 动态图形或 UI 录屏**量成可编辑场景 IR，再合成 HTML+GSAP、用 Chromium 渲帧并可出 MP4。你点名每个元素「保留 / 改什么」；真人实拍会被拒绝。流水线：`analyze`（视频→IR）→ `compose`（scene.json→HTML+GSAP）→ `render` → `verify` → `correct`（`reassign` / `mask` / `bbox` / `text`）。本地 `keepframe serve` 开 Maker UI（默认韩文，可切英文），也有 Docker 镜像 `westernbear/keepframe:0.1.0`。限制：只要平面 2D；每次编辑必须带 keep 谓词；修复重试上限 4、资源生成上限 2。

**何时用。** 手里只有竞品/旧版 UI 录屏，想拆成可改的 GSAP 场景再换文案、遮罩或框，而不是从零手动画。

**可带走的一点。** 先 `analyze --video ref.mp4 --start 0 --end 90`，再用 `correct` 改元素而不是直接改渲好的帧；`--end` 是闭区间。验证关卡 `verify` 看的是 schema、keep 谓词和帧对比——改完再渲，别跳过。
