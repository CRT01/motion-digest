# 动效简报 · 2026-08-24

周末窗口只有一条值得装：一份只写规格、不写实现的动效 skill。

### [design-motion](https://github.com/simota/design-skills)

**类型：** skill / 规范

**是什么。** simota 的 design-skills 七件套之一，2026-08-22 首次提交。整套都不写实现代码，只交「带依据的决定」。design-motion 管变化怎么被读懂：目的、编排、时长/缓动 token、打断行为、作为设计变体的 reduced-motion、交接。安装：git clone 后 make link，各 design-* 分别链到 ~/.claude/skills。skills.sh 上还没有 npx 条目。同套还有 design-tokens（存它定下的命名值）、design-critique / design-review（只出报告）。

**何时用。** 产品 UI 动效要先定规格再写曲线时。只要 GSAP/Motion 片段就别装。单行 hover 它会标 T0，跳过文书。

**可带走的一点。** 时长按位移和面积，不按组件类型：instant 75ms（色/透明/≤4px）、fast 150ms（≤100px）、base 200ms（下拉）、slow 300ms（半屏）、slower 400ms（全屏）。出场比进场低一档（300→200），不是 0.75 倍。进场 ease-out cubic-bezier(0.16, 1, 0.3, 1)，离场 ease-in。打断从当前位置反转，绝不重开。reduced-motion 改成只做透明度，不是删掉动效。每段过渡必须写齐触发、属性、打断、reduced 变体。只动 transform 和 opacity。
