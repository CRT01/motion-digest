# 动效简报 · 2026-09-25

过去两天产品向动效的重心在「先判该不该动」：一套带频率门禁与 79 道配方的完整 UI 动效体系、一套含品味审查的四技能包、一座可滚动体验的原生滚动词库展览，以及一份苹果向界面里把导航胶囊当成同一物理对象的工程 skill。盯着的 Emil / Motion / AlphaXe / mblode / animations.dev 本窗口没有新的产品级增量；优设检索也没有可带走的新规约。

### [all-in-motion](https://github.com/prewue/all-in-motion)

**类型：** skill / 规范 / 库

**是什么。** `prewue/all-in-motion`（9 月 22 日开源，昨日窗口补读）自称「把 UI 动效整件事一次做完」：判断层（该不该动、动多少、什么性格）、数值层（一套 token + 20 个实测弹簧预设）、配方层（79 条可粘贴 recipe，覆盖按压 / hover / 开关 / 下拉 / toast / 抽屉 / 表格展开行 / 手势等）、流程层（build → review → polish → audit）。技能本体在 `plugins/all-in-motion/skills/all-in-motion/`，带 `motion-tokens.css`、`motion-springs.css`、无依赖 `motion.ts`（WAAPI / Motion / react-spring / GSAP 预设）、`scripts/spring.py` 与静态红旗扫描器 `scan.py`。零依赖，可当普通 CSS 资产用，也可 `/plugin marketplace add prewue/all-in-motion` 装进 Claude Code。

**何时用。** 产品界面要统一动效语言、审 diff 里的动画、或要把「别再瞎写 duration」落到可扫描规则时。

**可带走的一点。** **先跑频率门禁：键盘触发或一天 100+ 次的动作永远不要动画——写出零行代码算成功。** UI 上禁止 `ease-in`；关闭要比打开更快更安静；从不做 `transition: all`、`scale(0)`、键盘动作上的动画；例外在代码旁标 `motion-ok: <原因>`，扫描器才会放过。

### [animation-skill](https://github.com/nguyenanhducdeveloper86/animation-skill)

**类型：** skill

**是什么。** 9 月 24 日开源的四件套：`web-animation`（意图 → 状态 → 层级 → 属性 → 曲线 → 时钟 → 降级 → 验收）、`gsap-scroll`（GSAP + ScrollTrigger + Lenis **同一时钟**与 `gsap.context` 清理）、`spatial-webgl`（共享 R3F Canvas、相机阻尼、预留可读中列、实例化与 WebGL 丢失回退）、`motion-taste`（克制优先的口味审查：做 / 不做与八项批判清单）。作者声明参考了 LottieFiles / Emil / GSAP / iart-ai 等公开模式，但是原创综合，不是拷贝。安装：`npx skills@latest add nguyenanhducdeveloper86/animation-skill`。

**何时用。** 做编辑型站点、滚动叙事、DOM↔WebGL 同屏，或审一份「像模板拼出来」的动效时。

**可带走的一点。** **一个视口只留一个时钟：CSS 管独立微交互，GSAP/Lenis 共用 ticker，R3F 另开一条渲染环——不要三套 RAF 抢跑。** 入场用减速曲线（如 `power3.out`），出场用加速（如 `power2.in`）；标签 / 指标 / 正文别弹；`prefers-reduced-motion` 要去掉位移与惯性，不是去掉内容。

### [mocubix](https://github.com/renocrypt/mocubix)

**类型：** 设计哲学 / 规范 / 展览

**是什么。** `renocrypt/mocubix`（9 月 23 日起建，24 日仍在推）是一座纯前端的滚动交互展览：七个主题展厅 + **41 条命名界面效果词库**（五柱：滚动驱动、滚动行为、图像、字体、色彩），每条词有独立页，写清从业者叫什么、机制是什么。技术栈刻意压到 Chrome 原生：`animation-timeline`、scroll-triggered、`@property`、View Transitions、`corner-shape`，无框架无依赖。9 月 24 日的增量还包括：对照 Chrome 154 实测 `scroll-state` 查询（stuck / snapped / scrollable / scrolled），以及 `docs/MEASURED-ANATOMY.md`——对 cerebrium.ai 等真站做 `getComputedStyle` 面积加权的字体 / 色 / 缓动普查，把「奖项文案」和「浏览器实测」分开。站点：https://mocubix.renocrypt.com/

**何时用。** 要给滚动动效起准名、对照原生 CSS 能力做原型，或需要「测得到」的参考解剖时。

**可带走的一点。** **scrolled 状态只对相对滚动（`scrollBy`、键盘）成立，对 `scrollTo` / `scrollIntoView` 不成立——写进 trap，别当通用钩子。** 缓动别靠眼：MEASURED-ANATOMY 里连获奖站都常落在默认曲线上；先普查再定 token。

### [LGMDS](https://github.com/letimcook/lgmds-apple-inspired-interface-engineering)

**类型：** skill / 规范

**是什么。** `letimcook/lgmds-apple-inspired-interface-engineering`（9 月 22 日，v1.2.0）把 Liquid Glass · Glassmorphism · Motion · Design · Systems 收成一份可路由的 skill：先过证据规则与十项首轮诊断，再按任务加载 `references/`（材料、动效工程、导航动效、品牌动画、SwiftUI、Web、Lottie/Rive 选型、设计系统、无障碍）。动效宪章要求每条动画只承担 Reveal / Response / Transition / Validation / Focus 之一；导航规则强调「选中胶囊是同一物理对象，禁止拆掉重建来假装滑动」。提供 `/lgmds-motion`、`/lgmds-navigation` 等 Claude Code 斜杠命令。安装：`npx skills add letimcook/lgmds-apple-inspired-interface-engineering`。

**何时用。** iOS / SwiftUI 或 Web 上要做苹果向手感（尤其是玻璃材料 + 会旅行的 tab 指示器），又要避免「模糊+透明度=高端」时。

**可带走的一点。** **流体 tab 的概念序列是：press → 沿方向拉长 → 旅行 / 桥接 → 终点压缩 → settle——全程是一个持续存在的材料对象。** 时长起点：微响应约 120–220ms，普通 UI 过渡约 220–420ms；弹簧用在有空间连续性的对象上，禁止把弹跳当装饰。
