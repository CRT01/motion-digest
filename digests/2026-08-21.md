# 动效简报 · 2026-08-21

今天早上的定时任务跑过，过去 48 小时没有新发布，所以没推。这次按「尚未归档」补三份通读过的条目：Emil 三透镜审查、场景配方库、Motion UI 组件。

### [design-motion-principles](https://github.com/kylezantos/design-motion-principles)

**类型：** skill

**是什么。** kylezantos 的动效 skill，安装：npx skills add kylezantos/design-motion-principles。两个模式：Create（写组件动效）和 Audit（审查现有动效，默认吐一份带循环 CSS demo 的 HTML 报告到 motion-audits/）。三套透镜来自公开资料的蒸馏，不是本人背书：Emil Kowalski 问该不该动，Jakub Krehel 问够不够克制，Jhey Tompkins 问还能玩成什么样。会按产品类型加权：生产力工具偏 Emil，落地页/作品集偏 Jakub+Jhey。审查还有 anti-AI-slop 清单：到处 hover-scale、stagger 滥用、工具操作上弹弹簧、进场 scale(0) 等。

**何时用。** 要按 Emil 那套写或审产品 UI 动效，又想同时听到另外两套品味时。

**可带走的一点。** 高频和键盘操作不要动效；生产力界面 180ms 为佳、不超过 300ms。Create 模式自检禁止 scale(0) 起步和裸 ease。

### [motion-ref-skill](https://github.com/joepUI/motion-ref-skill)

**类型：** skill / 配方库

**是什么。** joepUI 的场景向动效 skill。安装：npx skills add https://github.com/joepUI/motion-ref-skill。119 个可上线效果，分 13 类（加载、按钮反馈、浮层、表单、滚动、列表、状态、氛围、图表、进出场等）。用法是用产品语言描述问题（点了没反应、加载白屏、想高级一点），它先匹配场景再给 1-3 个方案和代码。有中文 SKILL.md。现场预览：https://joepui.github.io/motion-ref-skill/

**何时用。** 还不会动效术语、只想按场景抄一份能上线的 CSS/JS 时。它不管品味审查，管落地配方。

**可带走的一点。** 常规交互 200-500ms；低于 100ms 用户感觉不到，超过 500ms 像卡。方案必须带 prefers-reduced-motion。

### [Motion UI](https://motion.dev/ui)

**类型：** 组件 / 文档

**是什么。** Motion 官方营销站区块和组件集（Hero、Features、Pricing、FAQ、CTA、Nav、Carousel、Dialog 等）。不是昨日种子里的 AI kit。0.0.2（2026-08-13）加了 toast 栈。主题 token 有 snap / ui / gentle / lively / ambient 五套弹簧。

**何时用。** 已经用 Motion 做落地页或营销站，想直接抄官方区块而不是从零写 spring 时。

**可带走的一点。** 官方 toast 是堆叠而不是铺开；主题先选一套弹簧再改单组件，避免每个区块自己一套手感。
