# 动效简报 · 2026-09-22

周末之后 48 小时窗口里，值得单独成条的是三个方向：带功能契约的网页动效库、把动效当探索透镜的 agent skill、以及一条几乎不动排版的选区框组件。盯着的 Emil / AlphaXe / mblode / Motion 等仓库没有新的产品级增量。

### [Kineto](https://github.com/catgarret/kineto)

**类型：** 库

**是什么。** `@dong-gri/kineto`（v0.11）是一套 **54 个模块** 的网页动效 / 媒体库：用 `data-kt-*` 挂到现有 DOM，或走 JS / React / Vue / jQuery 适配器。核心不捆绑 GSAP / Lenis，按需从 CDN 拉引擎；也有 `core` + 单模块注册的瘦入口。公开范围锁在 `FEATURE_CONTRACT.md` 与 `kineto.features.json`——删改模块要走合约，不拿「难实现」换弱效果。对 agent 友好：`ai/kineto.rules.md`、`/llms.txt`、以及 `npx @dong-gri/kineto-mcp`（suggest / snippet / validate）。9 月 21 日前后仍在加 **gesture 的 `pull` 变体**（下拉刷新）、mega-menu 径向布局，以及 Core 上的 **Named Motion States**（`Kineto.states`）：只动 opacity / transform / 有限 filter，`apply` 可取消，reduced-motion 直接落到终态。在线可调参再复制 HTML / Vanilla / React / Vue / CSS 变量：https://kineto.dongri.me

**何时用。** 已有 shadcn / Ant / Bootstrap 等组件库，只想补入口、指针反馈、懒加载质感、下拉刷新，而不想再开一个「全量动画框架」；或要给 coding agent 一份「意图 → 模块」配方表时。

**可带走的一点。** **阻力放在手势末端，不要放在起点。** `pull` 源码写得很清楚：若从零就用指数衰减，达到 60px 阈值往往要拖 157px，手感像坏了；正确做法是阈值前近似线性跟随，过阈值后再渐近到 `max`。另外：reduced-motion 下弹簧可静音，但刷新手势仍要能完成——「安静」不能等于「控件失效」。同一元素不要叠两个写 `transform` 的模块。

### [atelier/motion（IamK77）](https://github.com/IamK77/Skill/blob/main/skills/atelier/motion/SKILL.md)

**类型：** skill / 设计哲学

**是什么。** `IamK77/Skill` 里 atelier 套件的 **motion 启发式透镜**（不是时长表、也不是「必须上动画」清单）。9 月 19 日仓库把执行 SOP 与创意启发式拆开；motion 这条明确写成：把动效当节奏、连续性、性格与叙事来 **探索可能性**，静止也是一种方向。配套参考很短但在点上：`gesture-arbitration`（先给模糊手势一个所有权合同）、`motion-purpose-and-physics`（弹簧是表现模型不是物理证明）、`reduced-motion-and-performance`（先做保留信息的静止版，再比动画多了什么）。装法走仓库 skills 目录或 agent skill 安装；描述写的是 invent interaction possibilities，不是 enforce one universal motion budget。

**何时用。** 评审前需要几条真正不同的动效方向，而不是立刻填 `duration` / `stiffness`；或 agent 一开口就甩弹簧预设、你想先逼它比较「有运动 / 无运动」时。

**可带走的一点。** **先做「同一事件的静止版」，再决定动效贡献的是连续性、强调，还是噪音。** 水平拖与竖直滚冲突时，不要先做漂亮动画原型——先定谁拥有手势（延迟承诺、显式手柄、或换交互），再上真机测打断。

### [ram](https://github.com/mirayavandiepen/ram)

**类型：** 组件

**是什么。** `@mirayavandiepen/ram`：给 React 文本包一层 **设计工具式选区框**——发丝描边、四角手柄、实时 `width × height` 标签。零依赖，继承父级字体；默认 `tracking` 动画只轻推字距，**周围排版不跟着挤动**。触发支持 mount / hover / click / 受控 `active`；尊重 `prefers-reduced-motion`。9 月 20 日前后正式以该包名发布并补上演示录屏。不是动效库，是一条可复用的「被选中」产品手感。

**何时用。** 营销标题、文档站、设计系统站点里要暗示「这段字可被选中 / 可被编辑」的氛围，又不想上整套光标追随或滚动剧场时。

**可带走的一点。** **选区反馈可以很炫，但正文几何必须稳：框和标签叠在文字外，字距呼吸不要推动同行其他字。** 默认时长偏叙事（约 1400ms tracking + 1200ms hold）；产品 UI 里若只做状态反馈，把 `duration` / `holdDuration` 压短，或改 `animation="static"` 只淡入框。
