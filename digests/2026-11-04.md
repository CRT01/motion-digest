# 2026-11-04 动效日报

今日五件：Emil 把 Interaction Lab 公开到 aiforui.dev/lab 可直接玩；tastecheck 的 micro-motion 把「先定终态与中断」写进合同；Taste Engine 的 taste-motion 按风格档路由时长（brutalism 可为 0ms）；中文「已看画面」核验的 UI 动效灵感库；以及 Liquid Glass Web 把按压缩放做成 280ms 弹簧胶囊控件。

### [Interaction Lab · Emil 公开可玩的交互实验室](https://aiforui.dev/lab)

**类型：** 设计哲学 / 实验台

**是什么。** Emil Kowalski 于 2026-11-03 公开了 Interaction Lab（推文：[Published my interaction lab…](https://x.com/emilkowalski/status/2117651655680463347)），地址 [aiforui.dev/lab](https://aiforui.dev/lab)。十月底 digests 写过「按规则日更、只留喜欢的」那套生成系统；这次是**可打开、可拖可点**的四宫格实验室，而不是只有概念。现场可见：顶右栏哲学文写明 *Animate to explain, not to decorate*、过渡要交代来去、多数界面动效落在 **300ms 以内**，并带 draft→final 滑杆；底右是弹簧台，示例 `stiffness: 180 / damping: 8 / mass: 1.0`，曲线标注 settle ≈ 0.84s，可拖参数、拖质量、点步长；另有排版扭曲球与 reaction-diffusion 生成格。站点本身是 AI for UI（aiforui.dev）课程侧的 lab，不是 npm 包。

**何时用。** 校准「该不该动、弹簧该不该晃」的体感，或给 agent/同事甩一个具体参考画面，而不是再贴一段空泛「要有品味」。

**可带走的一点。** 先问「是否在解释变化」；多数产品 UI 动效应压在 300ms 内——弹簧演示里 0.84s settle 是教学体感，不是高频控件默认。

### [micro-motion · 先定终态与中断的微动效合同](https://github.com/kyanitelabs/tastecheck/tree/main/skills/micro-motion)

**类型：** skill

**是什么。** kyanitelabs/tastecheck（前端品味 + 出货闸）里的 [`skills/micro-motion`](https://github.com/kyanitelabs/tastecheck/blob/main/skills/micro-motion/SKILL.md)：动效只确认变化、来源或下一步注意点，三者皆无则删。硬规则包括 compositor 优先 `transform`/`opacity`、按方向选缓动、reduced-motion 要等价态、**JS 未就绪前静态 CSS 不得藏内容**、循环可控且不 scroll-jack。时长 token 带：acknowledgement 120–160ms、insertion/menu 160–220ms、confirmation/route 220–320ms；交付物是 choreography 表（目的、触发、时长/缓动、settled、中断规则、reduced 等价）。附 [`assets/motion-tokens.css`](https://github.com/kyanitelabs/tastecheck/blob/main/skills/micro-motion/assets/motion-tokens.css)（`--dur-fast 150ms` / `--ease-out cubic-bezier(0.16, 1, 0.3, 1)` 等）与 [`references/principles.md`](https://github.com/kyanitelabs/tastecheck/blob/main/skills/micro-motion/references/principles.md)（FLIP / View Transitions、按交互类型的时长表）。仓库 2026-11-03 仍在活跃推送。

**何时用。** 给 agent 写/审按钮、浮层、列表插入时，需要「可中断 + 无 JS 也可读」而不是只抄 easing。

**可带走的一点。** 滚动揭示用 `data-reveal="pending"`：**默认可见**，观察者就绪后才给离屏元素打 pending；`pageshow`（bfcache）要清标记——别在静态 CSS 里 `opacity: 0` 赌 JS 一定跑到。

### [taste-motion · 按风格档路由的动效（可为 0ms）](https://github.com/kennedys0/taste-engine/tree/main/optional-standalone-skills/taste-motion)

**类型：** skill

**是什么。** [kennedys0/taste-engine](https://github.com/kennedys0/taste-engine)（2026-11-02 起公开，MIT，v0.10.5）的可选动效伴生 skill：先尊重既有风格，不擅自装动画库。核心文档 [`references/motion-engine.md`](https://github.com/kennedys0/taste-engine/blob/main/optional-standalone-skills/taste-motion/references/motion-engine.md) 写清：CSS/项目已有方案够用就不加 Anime.js v4；若装则用 `import { animate, createScope } from 'animejs'`（禁 V3 默认导入），React 里 `createScope` + `scope.revert()`。质量分 FLOOR / REFLEX / FINISH；[`motion-profiles.json`](https://github.com/kennedys0/taste-engine/blob/main/skills/taste-engine/styles/motion-profiles.json) 按风格给起点——brutalism / retro-terminal **0ms**，enterprise **110ms**，neo-brutalism **130ms**，glass/clay/bento **180ms** 等，并写明各档 avoid（如 glass 勿动画 blur、enterprise 勿 stagger 表格）。安装：`npx skills add kennedys0/taste-engine --skill taste-engine`（完整包）或单独 taste-motion 目录。

**何时用。** 项目已选定视觉风格（或走 Taste Engine 预检），需要「这风格该不该弹簧」的可执行默认，而不是全局同一套 Motion 菜谱。

**可带走的一点。** 风格决定时长上限：brutalism 即时翻转是合法答案；别给数据密集 enterprise 表加入场 stagger。

### [UI 动效灵感库 · 369 条「已看画面」核验](https://github.com/Spr1ng-zbm/ui-motion-inspiration-library)

**类型：** 组件 / 灵感库

**是什么。** 2026-11-03 整理的中文灵感库（[GitHub](https://github.com/Spr1ng-zbm/ui-motion-inspiration-library) / [在线浏览](https://spr1ng-zbm.github.io/ui-motion-inspiration-library/)）：主库 **369** 条具体 UI、可交互演示与作品展示；强调**实际看过画面**才入库，教程/泛导航/占位页剔除。审计文档写明旧库 173 条复核后留 158、新加 211；分类含完整界面 110、微交互 78、画廊导航 49 等。条目区分产品展示与可交互 demo，视频只核验关键片段。样例覆盖 Motion App Store 卡片展开、Sonner/Vaul、60fps.design 触感标签、Kokonut 滑动确认等产品向参考。

**何时用。** 找「这种反馈长什么样」的可点击/可播放证据，而不是再刷未验证的 awesome 列表。

**可带走的一点。** 收藏链接前先问：我是否看见状态变化？看不见就别写成「已验证动效」——HTTP 200 ≠ 动效可用。

### [Liquid Glass Web · 280ms 弹簧胶囊与两层结构](https://github.com/tgallina-hub/liquid-glass-web)

**类型：** skill / 规范

**是什么。** 2026-11-03 发布的 Agent Skill：把 Apple「Adopting Liquid Glass」公开指引改写成**浏览器**设计系统（无 SF Symbols/Apple 字体）。内容层不透明，玻璃只留给导航与控件；[`references/brand-book.md`](https://github.com/tgallina-hub/liquid-glass-web/blob/main/liquid-glass-web/skills/liquid-glass-web/references/brand-book.md) 的 Motion 节写明按压用短弹簧、菜单从触发按钮长出。实现上 [`assets/liquid-glass.css`](https://github.com/tgallina-hub/liquid-glass-web/blob/main/liquid-glass-web/skills/liquid-glass-web/assets/liquid-glass.css) 定义 `--lg-dur: 280ms`、`--lg-ease: cubic-bezier(0.32, 0.72, 0, 1)`（与 Emil/Vaul 抽屉曲线同族）、`--lg-ease-spring: cubic-bezier(0.34, 1.4, 0.64, 1)`；`.lg-btn:active` 为 **`scale(1.06)`（放大）** 而非常见缩小；`prefers-reduced-motion` 把时长压到 1ms。附 token、对比度脚本与组件文档。

**何时用。** 要做 Web 端液态玻璃导航层，并需要可拷贝的时长/按压约定与 a11y 主题（含 contrast / reduced-transparency）。

**可带走的一点。** 玻璃只做功能层；动效 token 与材质 token 分开——按压反馈可以在 CSS 里，但别把 blur 半径拿去插值动画。
