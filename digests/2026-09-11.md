# 动效简报 · 2026-09-11

这窗口两份：一份用真实录屏做动效取证的 MCP skill，一份把 Emil / Krehel / Jhey 三透镜写进可装 agent 合集的 motion-core。

### [seenry-motion（Seenry skills）](https://github.com/ayangabryl/seenry-skills)

**类型：** skill

**是什么。** 9 月 10 日发布的 Seenry 研究 skill 包之一：`seenry-motion` 专管「先看交互、再写动画」。它接官方 MCP `https://mcp.seenry.design`，用 `search_references(motion=true)` / `get_page_motion` 拉网站录屏，用 `search_designs(family="motion")` + `get_design_video` 拉创作者动效研究片。skill 反复强调：海报帧不能证明时长/缓动/触发；编码帧率不等于有效采样帧；网站旅程录屏与 authored motion study 用途不同。安装：`npx skills add ayangabryl/seenry-skills`，再连上 MCP。

**何时用。** 要仿一段真实站上的 hover / 滚动 / 进场，或给 agent 一段「可检验的参考片」而不是凭空编弹簧参数时。

**可带走的一点。** 交互动效写清五段：**初始态 → 触发 → 过渡 → 落稳态 → 中断行为**；估计时长要标成估计。参考片不能证明性能或 a11y——实现后还得自己测快速连点、反向、中途离开和 `prefers-reduced-motion`。

### [Codex-Skills · motion-core / design-motion-principles](https://github.com/TheGoat395/Codex-Skills)

**类型：** skill / 设计哲学

**是什么。** Codex 优先的公开 skill 合集（80 个）里，动效线在 9 月 10 日质量审计里被统一修好：`design-motion-principles` 用 **Emil Kowalski / Jakub Krehel / Jhey Tompkins** 三透镜做 Create+Audit；另有 `motion-react-microinteractions`、`animation-easing-language`、`reduced-motion-design`、`motion-react-page-transitions` 等。装法：`python3 scripts/install_skills.py --collection motion-core`（也可装全量 `public-core`）。不是组件库，是给 agent 的动效决策与实现约束。

**何时用。** 想让 agent 先按产品语境选透镜（生产力偏 Emil，消费级打磨偏 Jakub，创意站偏 Jhey），再写或审 React/CSS 动效时。

**可带走的一点。** **频率门禁**：月级可玩、日级要克制、一天上百次的控件别拖时间线；键盘触发优先即时反馈。入场可用 Jakub 配方（opacity + 约 8px `translateY` + 4px blur），**退场要比入场更轻**（例如固定 `-12px` 而非对称大位移），别跟下一屏抢注意力。产品控件时长约 120–220ms、清晰 ease-out；严肃界面默认别上 bounce。
