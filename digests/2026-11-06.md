# 2026-11-06 动效日报

今日六件：Quegenx 的 ui-animation 把 Emil 频率门闩写进生产时长表；Codex `motion-design-principles` 给出可入库的时长/缓动 token；mthines 状态编排强调 FLIP 前先规划、飞行中别裁切；PulsoIcon 给每枚 lucide 替身独立 hover 动效；Flutter 液态玻璃 skill 钉死 12 个弹簧 token；Ant Design 6.7 的 Typography `shimmer` 把「思考态」文案做成 API。

### [Quegenx ui-animation · 频率门闩 + 时长表](https://github.com/Quegenx/agent-skills/tree/main/skills/web-ui/ui-animation)

**类型：** skill

**是什么。** [Quegenx/agent-skills](https://github.com/Quegenx/agent-skills) 的 [`ui-animation`](https://github.com/Quegenx/agent-skills/blob/main/skills/web-ui/ui-animation/SKILL.md)（路径于 2026-11-05 仍有更新）是一份大型 Web 动效 playbook：按任务路由到 [TIMING](https://github.com/Quegenx/agent-skills/blob/main/skills/web-ui/ui-animation/TIMING.md)、PATTERNS、GESTURES、PERFORMANCE、AUDIT 等参考文件，覆盖 Motion + CSS + View Transitions（RN 另开分支）。入口先问 Emil 那套失败模式——该不该动比怎么动更重要；工具链从 CSS → `@starting-style` → WAAPI → Motion 由便宜到贵。TIMING 把频率写成硬表：一天 100+ 次（键盘快捷键、命令面板）→ **永远不要动画**；数十次 → 近乎不可见或没有；偶尔（模态）→ 标准；稀有/首次 → 才有「delight 预算」。

**何时用。** 给产品 Web 加/调/审动效，或模型只会写「丝滑」却给不出数字时。

**可带走的一点。** 先过频率门闩；UI 时长可抄：按压 120–180ms、模态 300–400ms；stagger 总预算约 **500ms**（密集网格 20–40ms/项，只动可见前 8–12 项）；手势交接必须用 `stiffness/damping/mass` 物理弹簧，不要指望 `visualDuration` 弹簧继承释放速度。

### [Codex motion-design-principles · token 化时长与编排](https://codexskills.dev/skills/design/motion-design-principles/)

**类型：** skill / 规范

**是什么。** 2026-11-04 首发的 Codex Agent Skill（MIT，[`SKILL.md`](https://codexskills.dev/downloads/motion-design-principles.zip)）：库无关的产品动效语言——何时该动、按时长/尺寸选 duration 与 easing、进出不对称、编排与 stagger、状态间空间连续、弹簧参数、以及保留语义的 reduced-motion。安装：`curl -fsSL https://codexskills.dev/install.sh | sh -s -- motion-design-principles`。时长 token：`--dur-instant` 100ms、`--dur-fast` 150–200ms、`--dur-base` 250ms、`--dur-slow` 350–400ms；重复触发的交互禁止 >500ms。进场 ease-out、退场 ease-in 且约短 20–30%；列表 stagger 20–40ms/项，只 stagger 前 6–8 项，整组 ≲400ms；入场位移 8–24px，别整屏飞入。

**何时用。** 定义设计系统动效 token，或审计「又慢又乱、像装饰」的动画。

**可带走的一点。** 没有目的就删；有目的就换成 token，而不是再发明一个 420ms 的 `ease`。

### [mthines state-choreography · FLIP 前先规划](https://github.com/mthines/agent-skills/blob/main/skills/design/animations/rules/state-choreography.md)

**类型：** skill

**是什么。** [mthines/agent-skills](https://github.com/mthines/agent-skills) 的 [`animations`](https://github.com/mthines/agent-skills/blob/main/skills/design/animations/SKILL.md) 是薄索引（CSS 优先，再 WAAPI / Motion / View Transitions）；高影响细则在 [`state-choreography.md`](https://github.com/mthines/agent-skills/blob/main/skills/design/animations/rules/state-choreography.md)：列表↔堆叠卡片、导航收成图标、卡片→详情、同页 DOM 交换。硬规则是**写代码前走规划清单**：命名 A/B 态、逐元素列变更、定 `layoutId` / `view-transition-name` 身份、进出件、timing 模型（Simultaneous / Layered / Lead-and-follow）、弹簧还是曲线、无障碍风险。工具决策表按信号选 Motion `layout`、`layoutId`、View Transitions 或手动 FLIP。

**何时用。** 结构真的变了的布局变形（不是单纯 fade），或纠结 CSS vs Motion vs VT。

**可带走的一点。** FLIP 飞行中父级不要挂 `overflow: hidden` / `clip-path` / `contain: paint`——子节点的中间 `transform` 会落在裁切外而「蒸发」；保持 `overflow: visible` 直到 `onLayoutAnimationComplete`，静止后再恢复滚动裁切。

### [PulsoIcon · 每枚图标独立 hover 动效](https://github.com/CityPulso/PulsoIcon)

**类型：** 组件 / 库

**是什么。** [pulsoicon](https://www.npmjs.com/package/pulsoicon) v5.2.1（npm 2026-11-04 起，最新 11-05）：约 **9955** 个 React 图标，**每一枚写自己的 motion**，不是统一盖一个 hover scale。静止是干净 24×24；hover/focus 最近的 `button` / `a` / `label` / tab / menuitem（或 `data-icon-trigger`）时播放。API 对齐 lucide-react（同名组件与 props），依赖 React + Motion；尊重 `prefers-reduced-motion`。三图标约 12kB（未压缩前），按模块 tree-shake。

**何时用。** 工具栏/导航里 lucide 太静，又想「铃铛会响、垃圾桶开盖」这类语义微反馈时——通常只改 import。

**可带走的一点。** `animated={false}` 完全静态；`autoAnimated={false}` + `ref.startAnimation()` / `play` 做意图触发（保存成功再播勾），别让每颗图标无脑自嗨。

### [liquid-glass-motion · Flutter 12 弹簧 token](https://github.com/zararogers338-hash/liquid-glass-motion)

**类型：** skill / 组件模板

**是什么。** 2026-11-05 公开的 Flutter Codex skill + 可运行 starter（[demo](https://zararogers338-hash.github.io/liquid-glass-motion/)）：以液态玻璃表面与可打断、保留速度的弹簧为核心，设计语言叫 **Prism**——结构靠填充、颜色给状态、运动靠弹簧。[`SKILL.md`](https://github.com/zararogers338-hash/liquid-glass-motion/blob/main/skills/liquid-glass-motion/SKILL.md) 给出 12 个弹簧 token（`track` 120/0 … `jelly` 630/0.6），按压语言分三种且不混用：内容 = ink（不缩放）、按钮 = tint、chrome = 弹性膨胀。附 `spring_lab.py` 审计裸时长/`easeOutBack` 冒充弹簧/`forward(from: 0)` 等隐患。

**何时用。** Flutter 里做 dock、sheet、开关、分段控件等玻璃/chrome 动效系统。

**可带走的一点。** **回弹只给几何**（位/尺/缩放/拉伸）；透明度、颜色、模糊 bounce 永远为 0；松手要把释放速度交给弹簧，禁止 `forward(from: 0)` 从零重播。

### [Ant Design 6.7 · Typography shimmer](https://ant.design/components/typography-cn)

**类型：** 组件

**是什么。** Ant Design [6.7.0](https://ant.design/changelog-cn)（2026-11-04）为 `Typography.Text` / `Title` / `Paragraph` 新增 [`shimmer`](https://ant.design/components/typography-cn)：布尔或对象，给文案流光「思考/生成中」态。`duration` 单位为秒：数字表示扫过时长并默认再等 1s；数组 `[motionTime, waitTime]` 分别设扫过与等待。同版 BorderBeam 新增 `items`，可按束设 `color` / `lineWidth` / `outset` / `size`（装饰向，别拿来当焦点/错误边框语义）。

**何时用。** AI「思考中…」、流式状态文案，需要产品级 API 而不是手写 CSS shimmer。

**可带走的一点。** `shimmer={{ duration: [motionSec, waitSec] }}`；BorderBeam 在 `prefers-reduced-motion` 下隐藏——流光可以点缀，不能替代焦点环或校验描边。
