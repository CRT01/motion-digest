# 动效简报 · 2026-08-25

昨天窗口只捞到一条：进场揭示的合同，不是整套动效系统。

### [entrance-motion](https://github.com/mathofdynamic/entrance-motion-skill)

**类型：** skill

**是什么。** mathofdynamic 的进场揭示 skill，2026-08-24 首次提交。只交说明书，没有运行时库。管页面/区块第一次出现：先审计现有架构，复用已有原语，IntersectionObserver 触发一次、不回放。装法：把 skills/entrance-motion/ 拷到 .claude/skills/ 或 .agents/skills/；Codex 可用 $skill-installer install 那个目录。不管 loading、视差、循环装饰，也不替换整套动效。

**何时用。** 给现有前端加或修区块进场。已经有 Emil animate 加 token 时，不必再装一套性格包，把下面那条抄走就行。

**可带走的一点。** 默认 100ms、cubic-bezier(.16, 1, .3, 1)、只动 opacity 和 translate3d(0, 20px, 0)。下一项在 duration/3（约 33ms）时起步，刻意重叠，绝不等上一项播完，也别把 33ms 写死。reduced-motion 去掉位移和 stagger，立刻显现。内容默认可见；只有 JS 确认启用动效后才藏初态，JS 挂了也不能把字藏起来。禁止 loading 屏和人为白屏。
