# 动效简报 · 2026-08-31

周末窗口两份新货：Vercel 把 React View Transitions skill 重写了一遍，sheleg 补上「动效变成文件」的边界。

### [React View Transitions](https://github.com/vercel-labs/agent-skills/tree/main/skills/react-view-transitions)

**类型：** skill

**是什么。** Vercel `agent-skills` 里的 `vercel-react-view-transitions`，2026-08-28 21:36 CST 合入大改（+733 / −316）。用 React 原生 `<ViewTransition>`：组件声明什么动，`startTransition` / `Suspense` 决定何时，CSS `::view-transition-*` 控制怎么动，不靠 Motion / GSAP。装：`npx skills add https://github.com/vercel-labs/agent-skills --skill vercel-react-view-transitions`。Next.js App Router 已带 canary，不要另装 `react@canary`。实现顺序：共享元素 → Suspense 揭示 → 列表身份 → 进出场 → 路由。

**何时用。** 要做页面、列表或共享元素过渡，又不想引入动画库时。

**可带走的一点。** 时长 token：`--duration-exit: 150ms`、`--duration-enter: 210ms`、`--duration-move: 400ms`。层级导航才用 60px 定向滑；tab 横向不要装空间深度。关掉 root 的 old/new 动画（live-root），未命名区域才保持可点。`prefers-reduced-motion` 把所有 VT 时长和延迟打成 0。Next.js 里先别推荐 `parentEnter` / `parentExit`。

### [Motion production](https://github.com/ssheleg/sheleg-design-skill/blob/main/.cursor/skills/sheleg-design/MOTION_PRODUCTION.md)

**类型：** 设计哲学

**是什么。** sheleg-design-skill 在 2026-08-30 加的 `MOTION_PRODUCTION.md`（v1.56.0）。`MOTION_DOCTRINE` 管页上能不能动；这份管动效必须变成文件（发布片、OG、社交切片）时怎么办。拒绝口令是 “no render”——hero 动效该留在页面。装：`npx skills add ssheleg/sheleg-design-skill`。

**何时用。** 已经决定要导出成片，而不是再做页内微交互时。

**可带走的一点。** 默认 HyperFrames：把 pack 的 `tokens/*.css` `<link>` 进去，不要转写成另一份色板。运动由页内状态驱动、产品本身是视频管线、或扛不住 pre-1.0 时才用 Remotion。渲染文件没有 `prefers-reduced-motion`，义务挪到嵌入页：reduce 下禁止 autoplay、真海报、控件。预检最后一项是字节级可复现重渲。
