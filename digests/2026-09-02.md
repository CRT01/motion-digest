# 动效简报 · 2026-09-02

窗口里一份值得装的 Agent skill：`mblode/agent-skills` 的 `ui-animation` 在 9 月 1 日补上滚动门禁、廉价感症状表和 SVG 陷阱，把「状态之间的通路」写完整了。

### [UI Animation（mblode/agent-skills）](https://github.com/mblode/agent-skills/tree/main/skills/ui-animation)

**类型：** skill

**是什么。** mblode 的 Agent Skills 仓库里专门管「两个状态之间怎么走」的 skill：CSS transition、WAAPI、spring、手势拖拽、缓动时长、Motion（`motion/react`）、滚动驱动动画，以及从录屏反推曲线。装：`npx skills add https://github.com/mblode/agent-skills --skill ui-animation`。它明确不是视觉方向（交给 `ui-design`），也不是「有哪些状态、动作可不可逆」（交给 `product-design`）；手势若替代控件，先由产品定能力，再由本 skill 写物理。参考文件很多：`spring-animations.md`（Apple damping/response、开合非对称、打断规则）、`transition-recipes.md`（容器 morph、模态、下拉、页滑、图标对换等）、`gesture-drag.md`、`performance-deep-dive.md`。9 月 1 日 PR #15 又补了三块硬货：`scroll-animations.md`（产品 UI 默认不做滚动揭示）、`debugging-symptoms.md`（迟钝/机械/廉价/卡顿/跳动/闪烁的症状表）、`svg-animation.md`（描边绘制、path morph、Motion SVG 原点陷阱）。另有 Discovery 工作流（「哪里该动」只报建议不写代码）和录屏反推管线（ffmpeg + 曲线拟合 → 代码）。

**何时用。** 给 Cursor / Claude 代理写或审查产品 UI 动效，或要从录屏复现一条过渡、排查「为什么看起来廉价」时。

**可带走的一点。** 实现优先级：CSS transition > WAAPI > spring > keyframes > JS；可打断的交互优先 transition（打断会重定向），keyframes 只用于预定序列。产品 UI 默认不要滚动揭示——那是营销页少数几次、只跑一遍、上滚不重播。觉得「廉价」时，先查 `scale(0.9–0.95)` 起点 + `transform-origin` + 小 blur 桥接，不要只靠加长时长。命名曲线：Enter `cubic-bezier(0.22, 1, 0.36, 1)`，Move `cubic-bezier(0.25, 1, 0.5, 1)`，Drawer（iOS 感）`cubic-bezier(0.32, 0.72, 0, 1)`。UI 禁用 `ease-in`；不要 `transition: all`；布局属性（width/height/top/left）不要动画。
