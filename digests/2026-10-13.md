# 动效简报 · 2026-10-13

今天三件产品/UI 车道里的新东西。头条是 `lucasgabrieldevgg/motion`：把多份开源动效 skill 合成一套「先手艺、后菜谱、最后选库」的大 skill，带 14 条 AI 动效死亡清单。其次是 `Danjc5ik/anti-slop-design`：从 35 个设计向站点实测出缓动/时长，并强制写六层动效计划，还附带 Playwright 审计。第三是 `domedad/frontend-animation-patterns`：按产品意图在九个 UI 动效目录里选型，而不是抄一整站皮肤。Emil / Motion / AlphaXe / 优设本窗口没有新产品动效 keeper；一批「产品宣传片 / Remotion 导演 / 3D 镜头飞行」仓库（如 `NovusEdge/motion-lab`、`capteeen/product-motion-skill`、`Nevoo/motion-skills`）按车道剔除。

### [motion（手艺优先的代码动效大 skill）](https://github.com/lucasgabrieldevgg/motion)

**类型：** skill

**是什么。** 2026-10-12 上线的合成 skill（MIT，上游保留各自许可）。作者把 `AThevon/genjutsu`、`iart-ai/web-animation-skills`、`greensock/gsap-skills`、`199-biotechnologies/motion-dev-animations-skill`、`agiwhitelist/auteur` 等对接到一份方法：Track 1（约 70%）是物理与编排——时长档、命名缓动、弹簧预设、不对称进出、频率法则、token；Track 2 是八种技术栈决策树（现代 CSS / WAAPI+FLIP / GSAP / Motion / SVG / Canvas·three / Lottie·Rive），外加约 30 条 vanilla + React 双写菜谱。核心契约写得很硬：每条动画必须回答反馈、连续性、方位、层级、或「配额内的愉悦」之一；每帧只动 `transform`/`opacity`；用户等待类动效硬顶 500ms；`prefers-reduced-motion` 分三级而不是一刀切；出片前要冻帧截图验过。`references/craft.md` 的频率法则按「每天播多少次」给预算：约 1000× 的 hover/toggle 只给 100–150ms；约 10× 的弹层 200–300ms；一生一次的 onboarding 才允许 400–600ms+ 编排。14 条 slop 死亡清单点名：永动循环、每段同一套 fade-up、`scale(0)`、`linear` 用在 UI 状态、超过 500ms 的等待动画、处处 bounce、段落上的视差、`transition: all`、劫持滚动等。npm 版本在 2026-10-13 对过 registry（含 `motion` 14.1.0）。

**何时用。** 要给 agent 一套「先想清楚再写代码」的动效纪律，或从多库菜谱里选型；`git clone` 进 `~/.claude/skills/motion`，Cursor 可拷 `exports/motion.mdc`。

**可带走的一点。** **频率法则：播得越勤，越要短、越要淡。** 默认弹簧先用 `stiffness: 400, damping: 30`（弹层/抽屉/Tab）；按压回弹用 `500/30`；需要可打断的手势才上弹簧，必须卡死可读时刻的揭示用 tween。

### [anti-slop-design（实测反廉价 + 六层动效计划）](https://github.com/Danjc5ik/anti-slop-design)

**类型：** skill

**是什么。** 2026-10-12 发布。不只反「AI 味」排版，动效章 `references/motion.md` 和 `assets/tokens.css` 来自对 Apple / Stripe / Linear / Vercel / Notion / Figma 等 35 个站点的实测：滚动动效在约 62% 站点出现且各自不同；工作曲线是 ease-out 族 `(.16,1,.3,1)`、`(.22,1,.36,1)`、`(.25,1,.5,1)`，而不是默认 `ease`；hover 100–200ms，大揭示 600–1000ms。强制在写代码前交一份六层动效计划：① 控件状态（hover/press/focus）② 组件开合 ③ 首屏入场编排（文案+CTA 约 1.2s 内可读）④ 2–4 个内容相关的滚动时刻 ⑤ 最多一个环境循环 ⑥ 每层都有 reduced-motion 版本。缺 1/3/6 或整页同一套 fade-up，就是两种典型 AI 结果。菜谱里有可抄的细节：按钮 `:active` 用 `scale(0.97)`、箭头单独位移而不是整钮乱晃；卡片悬停抬内容图（约 `scale(1.03)`）而不是整卡 `scale-105`；菜单用 `@starting-style` + `allow-discrete` 做 origin-aware 开合。附带 `scripts/audit.py`：Playwright 截桌面/手机、拍加载胶片，并对默认缓动、无动效、不可见焦点等报警。

**何时用。** 落地页/营销站看起来像模板、动效全是同一套 fade-up，或要在现有品牌里抬执行质量（技能明确：换工艺数值，不换品牌审美）。

**可带走的一点。** **先写六层动效计划再写 CSS；token 用实测曲线：`--ease-out-quart: cubic-bezier(0.25, 1, 0.5, 1)` 当 hover 主力，`--dur-fast: 160ms` / `--dur-base: 240ms` / `--dur-slow: 400ms`，大揭示才到 `--dur-reveal: 800ms`。** 装好后可用 `python3 anti-slop-design/scripts/audit.py index.html --out design-audit` 先抓一轮。

### [frontend-animation-patterns（九目录选型矩阵）](https://github.com/domedad/frontend-animation-patterns)

**类型：** skill

**是什么。** 2026-10-12 左右上线的目录型 skill：不发明新物理，而是在动手前读 `selection-matrix.md`，按「元素角色 + 交互目标」从九个维护中的前端目录里挑配方——EasyUI（遥测/批处理/支付反馈）、Beautiful UI（流式回答/工具调用/审批）、Rewamp UI（刻意的签名动效/WebGL）、beUI（可拷贝的 Motion 控件与 agent 界面块）、COSS UI（克制可访问的产品原语）、React Bits（标题/背景表现）、Transitions.dev（菜单/对话框/Tab/Toast 等产品态）、Magic UI（营销展示）、MicroInteractions UI（shadcn 控件级微交互）。工作流要求：先看清项目已有 token 与动画栈 → 把请求分成元素样式 / 交互状态 / 功能动效 / 表现型编排 → 最多提三个候选并推荐一个理由 → 写元素契约再实现 → 浏览器里验键盘、响应式、reduced-motion。硬规则包括：能用 CSS transition 的不要为单次 hover 加库；Magic UI 不能盲装，先确认 React/Tailwind/依赖；滚动叙事、时间轴、拖拽物理才考虑 GSAP skill。

**何时用。** 「这个按钮/对话框/AI 聊天态该长什么样、怎么动」却不想从零搜星标 demo；或 agent 总爱塞一整套营销动效进后台。

**可带走的一点。** **产品态变化先查 Transitions.dev / MicroInteractions UI；AI 工作台走 Beautiful UI；只有品牌签名时刻才上 Rewamp/Magic。** 选型从角色出发，不允许「看见炫就装」。
