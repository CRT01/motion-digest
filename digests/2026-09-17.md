# 动效简报 · 2026-09-17

窗口里两份硬货：Motion 13.4 把 `AnimateView` 放进开源包（基于 React 19.3 的 View Transition），以及 mblode `ui-animation` 补上正向调参路径并修掉滑动手势的方向判错。

### [Motion · AnimateView（13.4.0）](https://motion.dev/docs/react-animate-view)

**类型：** 库

**是什么。** Motion 在 9 月 14 日发的 13.4.0 把原先 Motion+ 早鸟里的 `AnimateView` 开源进主包：用浏览器原生 View Transition API，叠在 React 19.3 的 `ViewTransition` 上，由 Motion 的迷你 `animate()` 驱动。能力覆盖进场/退场、内容更新时的交叉淡入、以及同名元素的共享过渡（类似 App Store 卡片展开）。`transition` 吃完整套 Motion 选项，包括弹簧；也可按 `enter` / `exit` / `share` / `update` 分别配。自定义 `clipPath` 等值时会关掉默认透明度交叉淡入，需要时自己把 `opacity` 写回去。同日的 13.3.0 还把 `springValue` / `useSpring` 在重定向时的耗时砍了约 80%，`animate` 启动与逐帧开销也更轻。注意：要从 `"motion/react-animate-view"` 单独入口导入，且需要 React / React DOM ≥ 19.3；状态切换要包在 `startTransition` 里才会触发视图过渡。

**何时用。** React 19.3 项目里要做页面级/视图级过渡、列表重排、或「卡片变成详情」的共享元素动画，又不想继续绑 Motion+ 时。

**可带走的一点。** **导入路径是 `"motion/react-animate-view"`，状态变更必须包在 `startTransition` 里。** 共享过渡靠两侧相同的 `name`；同屏同名超过一个会直接失败。尺寸与位移可用 `transition.layout` 单独给弹簧，和透明度时长拆开。

### [mblode ui-animation · live-tuning 与手势修正](https://github.com/mblode/agent-skills/blob/main/skills/ui-animation/references/live-tuning.md)

**类型：** skill（增量）

**是什么。** 9 月 16 日 `mblode/agent-skills` 的 `ui-animation` 补了正向调参章 `references/live-tuning.md`：以前只有「录屏 → 拟合曲线」的反向路径，现在教你在没有参考片时，对着真正在跑的组件用 DevTools 贝塞尔编辑器和 Animations 面板拖时长/延迟，再把字面量写回源码。明确写了 DevTools 做不到弹簧和多阶段编排——那时才值得给项目加 DialKit / Leva / Tweakpane，且调完必须拆掉面板。同提交还重写了 Options 模式（用 URL 参数切换变体，不再依赖托管 picker），并修了 `gesture-drag.md`：滑动关闭忽略速度符号时，抽屉拖到八成关上再往回甩仍会关掉；现在先比幅值、再看符号、慢松手才用位置兜底。另外补了抓取偏移（按住元素内落点，避免首帧跳到指针下）和约 10px 的轴向锁定。

**何时用。** 时长/缓动吵不清、组件难复现（toast、多层 sheet）、或多相位 stagger 需要对着真界面调；或自写滑动关闭/拖拽时。

**可带走的一点。** **滑动关闭：幅值决定「够不够」、符号决定方向、慢松手才看位置。** 轴向在移动约 10px 后再锁定，避免列表里的横向滑删抢垂直滚动。调参结果必须贴回源码常量旁；控制面板是测量仪，不是交付物。
