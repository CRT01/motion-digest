# 动效简报 · 2026-09-24

过去 48 小时里，产品向动效多落在「可审计的判断」和「从真站拆出来的规格」：一套 Android Compose 动效规则 + MOTION.md 技能三件套、生产站抽出来的滚动动效 skill、以及把 live 站点拆成 MOTION-SPEC 的取证 skill。另外两条是带真机复测的移动端动效审计，以及可逐帧对齐的区块边缘 gooey 引擎。盯着的 Emil / Motion / AlphaXe / mblode 本窗口没有新的产品级增量。

### [android-ux-skills](https://github.com/rock3r/android-ux-skills)

**类型：** skill / 规范

**是什么。** `rock3r/android-ux-skills`（9 月 20 日开源，仍标 WIP）专门补 Google 文档不写的那一层：Compose / Material 3 Expressive 动效能不能动、该什么手感、打断与关动画后怎么办。核心是一份 34 条的 `STANDARDS.md`（10 floor / 2 obligation / 22 taste），以及围绕仓库级 `MOTION.md` 的三个 skill——`animate-compose`（先判该不该动再选型）、`improve-android-motion`（只读审计，写出可审批的 MOTION.md 与可执行计划）、`review-android-motion`（对抗式审查，必须引用规则 id，默认倾向挡）。作者明确说技能脚手架还在动，taste 规则还缺设计师审，但规则集本身已经按源码事实写过两轮修订。

**何时用。** Android / Compose 产品要立动效语言，或审 PR 时需要「能不能动」而不只是「API 对不对」时。

**可带走的一点。** **NavHost 默认那条约 700ms 的过渡本身就是 finding——M3 时长 token 顶到 `extraLong4`（600ms），长于自家上限的默认值说明没人选过。** 调用点禁止裸 `tween()` / `spring()`，数字只许出现在 token 定义里；产品决定写进 `MOTION.md` 的 `DECIDED`，否则不算标准。

### [scroll-animation](https://github.com/gabros20/scroll-animation-skill)

**类型：** skill / 库

**是什么。** 9 月 23 日开源的 Claude skill，从一座营销站「建了三代、删了两代」的动效层抽出来。把动画按时钟分流：**trigger**（到视口触发的入场，默认）、**scroll**（每页最多一个 pinned 场景）、**media**（scrub / 循环视频）。同一套 DOM attribute 合同，同时给 React + Motion 与 GSAP 两套 primitives（`Stage` / `StageItem` / `ScrubStage` / `PullToCentre` / `useHeaderTheme` 等），并带上 iOS Safari、视频编码接缝、与既有 Lenis/GSAP 共存的实测坑。配套 `fluid-design` 只管流体布局、不含动画。

**何时用。** 落地页 / 编辑页要上滚动揭示、钉住 scrub、或排查「移动端 reveal 不触发 / scrub 卡在第一帧」这类症状时。

**可带走的一点。** **先问谁在提供时间：trigger 几乎免费，scroll 要占一条跑道、一个 pin 和一个性能名额——默认不要。** 入场曲线是测出来的：`cubic-bezier(0.15, 0.6, 0.2, 1)` 跑 1.3s 位移，opacity 另开 0.17s linear、延迟 0.13s；`amount` 别写成视口比例（高块上会永远不触发），用 `margin` 定触发线。

### [website-style-miner](https://github.com/vyntizs-dev/website-style-miner)

**类型：** skill

**是什么。** 9 月 22 日上线的 agent skill：用带截图的浏览器打开真实 URL，把视觉身份、组件、响应式和**微交互 / 动效**拆成证据型 style book，并单独交付 `MOTION-SPEC.md`。动效章要求先 inventory 交互族（trigger、前后属性、时序、是否可逆、证据 id），区分视口触发 / 滚动 scrub / sticky 子内容变化，并把「测到的」与「重建用的校准值」分两张表写。没有浏览器视觉门禁就停，不拿纯文本 fetch 冒充审计。安装：`npx skills add vyntizs-dev/website-style-miner`。

**何时用。** 要复刻或学习某个线上产品的动效语言，需要可交给 coding agent 的规格，而不是形容词列表时。

**可带走的一点。** **动效交付分两表：证据账本（测到什么）vs 校准设置（建议时长 / easing / stagger，并标明是重建值）。** 点击不能代替 hover 时间线；`animation: none` 也不证明元素静态——CSS transition 声明管不到 JS 驱动的动画。

### [mobile-app-studio](https://github.com/ngnthanhdev/mobile-app-studio)

**类型：** skill

**是什么。** 9 月 23 日开源的 Claude skill，把 agent 固定成四角色顺序工作：资深移动 UI、产品设计、UX QA、**资深移动动效**。在模拟器 / 真机上当新用户走完旅程，对照 `references/motion-audit-checklist.md` 出 P0–P3，改代码后再在设备上以正常速度复测动效（截图不能判手感），并做第二轮「只看动效」巡检。覆盖 Expo/RN、Flutter、SwiftUI、原生 Android；可用 `--no-motion` / `--report-only`。

**何时用。** 上线前要做一轮「会动手改、会真机复测」的 UI + 动效打磨，而不是只出意见清单时。

**可带走的一点。** **时长起点：微交互 100–200ms，小状态 150–250ms，标准过渡 200–350ms，大过渡 300–500ms；进场 ease-out、出场 ease-in，手势跟指尖。** 问不清「传达了什么信息」的动效别加；列表长 stagger 是负担，不是精致。

### [ahoiadigital/claude-skills（gooey section）](https://github.com/ahoiadigital/claude-skills)

**类型：** skill / 组件

**是什么。** 9 月 23 日公开的一套区块边缘 skill：九种「液体分界」手感（Goo / Taffy / Wave / Honey / Peel / Slosh / Elastic / Drift / Twin），共享同一份从 Louis motion lab **逐帧校验过的引擎**（`assets/gooey-section.js`），skill 要求 agent **复制引擎、禁止用 GSAP/CSS 重写**。默认 Goo：σ 约 210px、拉力 2.2×滚动速度（封顶 150px）、升起约半秒、松开无过冲。支持纯 HTML、Webflow 自定义属性、React/Next；每个变体自带 `demo/index.html` 与 preview。

**何时用。** 营销 / 编辑页要区块之间有可命名的液体边缘，且必须和参考 lab 手感对齐时。

**可带走的一点。** **手感活在二十来个调好的常数和逐帧物理里——重写引擎几乎一定会漂。** 把 `data-goo-edge` 标在分界线**下方**那个区块（被往上拽的是它的颜色）；页面第一节上面没有邻居，不要标。
