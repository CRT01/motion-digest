# 2026-10-30 动效日报

今天三件：Emil 自建「每日交互实验室」用规则批量造灵感再只留喜欢的；Motion 14.8 给 `transition` 加了自定义 `mixer`；以及一套可对比、可导出 CSS/React/Framer Motion 的交互 pattern 实验室 Morph-UI。

### [Emil 的 Interaction Lab · 按规则日更、只留喜欢的](https://x.com/emilkowalski/status/2115789995860517254)

**类型：** 设计哲学

**是什么。** 2026-10-29 Emil 发帖并附约 46 秒演示：他给自己搭了一套 **interaction lab**——按预先写好的规则每天生成新交互，样子还很粗糙，但当灵感源够用；**只保留自己喜欢的**，所以久而久之越来越像他的偏好。演示是黑底双栏实验卡，带公式、实时参数与操作提示，例如：Accretion（hover 拉 / 按住再松）、Grown to shape（粒子长成 toggle 外形）、Mercury（粘性流体拖甩）、Path（沿 SVG `d` 拖「缝」改铃铛轮廓）、Palimpsest（draft↔final 滑条叠字）、Reaction-diffusion / Contours（擦掉再愈合）、Stir（搅动粒子场）、Level（拖倾斜让字里液面找平）、Loupe（放大镜读小字）。不是产品组件库，而是 **用生成器练品味** 的工作流。

**何时用。** 觉得自己或 agent 总在同一套 hover/fade 里打转；想建立「可丢弃的大量草稿 → 只留下对的」的口味校准环。

**可带走的一点。** 别指望一次提示词吐出最终交互：先写死规则，批量生成，再无情删——留下来的那一小撮才是你的 motion 品味。

### [Motion 14.8.0 · transition.mixer 自定义关键帧混合](https://github.com/motiondivision/motion/releases/tag/v14.8.0)

**类型：** 库

**是什么。** 2026-10-29 发布的 Motion **14.8.0**（changelog / GitHub CHANGELOG 一致）。唯一公开新 API：`transition.mixer`——替换「两段非数字关键帧之间」的默认混合器。签名是 `(from, to) => Mixer | undefined`：返回 `(p) => value`（`p` 可为弹簧过冲后的 >1 / <0），或返回 `undefined` 让这对关键帧走原逻辑。类型注释里的例子：`morph` 只负责 morph 不同拓扑的 SVG `d`，`fill` 仍走默认色插值——`<motion.path animate={{ d, fill }} transition={{ mixer: morph }} />`。数字关键帧、以及 mixer 对所有对都 `undefined` 的动画，行为与不加 mixer 相同；真正用到 mixer 的值会落到主线程。附带修复：`recordStats` 只在运行时计数；加速动画 remount 后卡在 `initial`；`drag` 约 −20%、`m` 约 −6%；时间轴调整限制在 timeline scope。站点：https://motion.dev/changelog?lib=motion#14-8-0 。

**何时用。** 已在用 Motion，需要在动画里 morph 路径、复杂字符串，或默认 mixer 因拓扑不同而「跳到终点」的场景。

**可带走的一点。** 默认混不了的 `d` / 复杂串别再手搓帧：给 `transition` 挂 `mixer`，不关心的属性返回 `undefined` 即可。

### [Morph-UI · 12 交互 × 9 材质的可导出实验台](https://github.com/Quatree12/Morph-UI)

**类型：** 组件 / 工具

**是什么。** 2026-10-29 上线的开源实验台（GitHub Pages：https://quatree12.github.io/Morph-UI/ ）。真实 HTML/CSS/JS 预览，不是截图墙：12 个 pattern（Liquid Glass、Gooey/Metaball、Expandable Buttons、Floating Dock、Experimental Nav、Morphing Shapes、Radial Menus、Kinetic、Lens、Collapsible、Expressive Motion、Contextual Toolbar，另有 Sheet Drag / Parallax / Swipe Stack / Ripple 等扩展）、9 种材质、5 种外形；`StudioProvider` 把每个旋钮写成 CSS 变量（`--accent`、`--blur`、`--speed-mul`、`--bounce`…），没有「装饰性」空控件。可对比两套配置，并导出 **CSS / React / Framer Motion**——FM 导出会把 Spring 旋钮映射成 `stiffness`/`damping`；README 诚实写明多元素行为（metaball、radial、dock）导出的只是主组件骨架。尊重 `prefers-reduced-motion`，触控目标 ≥44px。

**何时用。** 要在真实控件上拧材质/速度/回弹再决定带走哪套；或给 agent 一份「对照着实现」的 pattern + token 起点。

**可带走的一点。** 先把「调节 → 可见效果」收成 CSS 变量契约，再谈导出；导出时写清局限，比假装组件完整更有用。
