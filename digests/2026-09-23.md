# 动效简报 · 2026-09-23

过去 48 小时最值得单独成条的是三件事：Motion 官方把「时间轴 + 专用改动效 agent」做成可装进本地 dev 的 Studio；一套刚上线的 design-engineering skill（含严格 motion 门禁）；以及一份带可复现反模式的中文 design-motion 规格 skill。盯着的 Emil / AlphaXe / mblode 等仓库没有新的产品级增量。

### [Motion Studio](https://motion.dev/magazine/introducing-motion-studio)

**类型：** 库 / 工具

**是什么。** Motion 团队在 9 月 22 日发布的 **视觉 + agentic 动效编辑器**：在 Vite / Next / Nuxt / Astro / Webpack 的本地开发环境里，页面上的 Motion 动画会出现在时间轴上，可拖轨道、改关键帧、切 easing / spring，预览就在真实站点上。配套的 **Ultramotion** 是窄范围、很快的改动效 agent（文章称多数量级快于一般 coding agent），只改当前草稿；定稿后 Apply 可写回源码，或接 Cursor / Claude / Codex。免费可用：安装、检视、本地时间轴编辑；agent 写回与 Apply 到源码要订阅。需要 Motion ≥ 13.3.0、Node ≥ 22.13。安装包是 `motion-studio`（npm 上 2.0.0 于 9 月 21 日发布）。文档：https://motion.dev/docs/studio

**何时用。** 已经在用 `motion` / `motion/react`，调参反复 reload 拖慢手感；或想让 agent 改「错落 120ms」这类时序，又不想每次整文件重写时。

**可带走的一点。** **小调参别再走「改代码 → 等 reload → 看一眼」回路——时间轴改本地草稿，满意再 Apply。** Vite 把 `motionStudio()` 放在 React/Vue 插件之前即可；Next 包一层 `withMotionStudio`，并另开 `npx motion-studio serve`。目前支持 `animate()`、`<motion.*>`、`useAnimate()`、`v-motion`；滚动动画与 motion value 还在路线图上。

### [stealth-skills · motion](https://github.com/paragonhq/stealth-skills/blob/main/skills/motion/SKILL.md)

**类型：** skill / 设计哲学

**是什么。** Paragon 在 9 月 22 日公开的 `paragonhq/stealth-skills`：15 个 design-engineering skill，从 [stealth.pm](https://stealth.pm) 资源蒸馏而来，明确对标 Emil Kowalski / Krehel 那条线。入口是 `stealth`；其中 **`motion`** 不是「怎么让它动」，而是一串闸门——先问多久见一次、有没有目的，再选最便宜的工具（CSS transition → keyframes → Motion → GSAP）、属性（基本只动 transform/opacity）、曲线、时长或弹簧、原点、打断与退出，同一变更里带上 reduced-motion。仓库还单独有 `interaction`（点击后 100ms 内的承认感）和 `scroll-and-webgl`。安装：`npx skills add paragonhq/stealth-skills`，或 `--skill motion`。

**何时用。** Agent / 自己动手时容易写出 `transition: all 0.3s`、卡片全员抬起、bounce 装饰；需要一份会否决「不该动」的清单，而不是又一张时长表。

**可带走的一点。** **键盘触发的动作必须同帧切换，不要动画——⌘K、Escape、j/k 上的动效读起来就是延迟。** 产品 UI 里 bounce 几乎永远不对；弹簧最多过冲一两像素，晃就加阻尼。出场大约是入场的 70%；超过约 400ms 的产品反馈就是在让用户等。

### [design-motion（design-skill-lab）](https://github.com/caocong1/design-skill-lab/blob/main/skills/design-motion/SKILL.md)

**类型：** skill / 规范

**是什么。** `caocong1/design-skill-lab`（9 月 21–22 日密集开源）是一套中文 README + 英文 skill 的「资深设计师」套件：brief、多方向、设计系统、全状态样稿、交接。其中 **`design-motion`**（0.1.1）负责要不要动、怎么动、规格表，以及在 `.design/motion/*.html` 里做可慢放 / 可打断 / 可关 reduced-motion 的原型；覆盖 CSS、WAAPI、Motion、GSAP，并指向 Flutter / SwiftUI / Compose 的 token 参考。0.1.1 不是空改版本号——作者在自用页面「贴纸砸入」动效上踩坑后，把三条可复现反模式写进 skill。在线目录：https://caocong1.github.io/design-skill-lab/

**何时用。** 要把动效当成设计交付物（规格表 + 可演示原型）交给实现，而不是只在实现仓库里随手写 transition；或排查「入场像播了两遍」这类诡异 CSS 动画时。

**可带走的一点。** **关键帧每一帧都写全要动的属性，并用 `animation-fill-mode: both`——末帧漏写 `opacity` 时，浏览器会插值回等待态的 `opacity: 0`，看起来像入场播两遍。** 不要同时在 `transform` 里旋转又设 `rotate` 属性（会叠成双倍再弹回）；第二个改 `animation` 简写的类会取消正在进行的入场，摘掉类名后又从头播——副动画要么跳过，要么拆到另一个元素上。
